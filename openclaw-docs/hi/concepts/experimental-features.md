प्रायोगिक सुविधाएँ स्पष्ट फ़्लैग के पीछे उपलब्ध पूर्वावलोकन सतहें हैं। स्थिर डिफ़ॉल्ट या दीर्घकालिक अनुबंध मिलने से पहले इन्हें वास्तविक उपयोग में और अधिक परखा जाना आवश्यक है।

- डिफ़ॉल्ट रूप से बंद, जब तक कोई दस्तावेज़ सीमित स्वचालित सेटअप नियम का वर्णन न करे।
- इनका स्वरूप और व्यवहार स्थिर कॉन्फ़िगरेशन की तुलना में अधिक तेज़ी से बदल सकता है।
- यदि कोई स्थिर मार्ग पहले से उपलब्ध है, तो उसे प्राथमिकता दें।
- पहले छोटे परिवेश में परीक्षण करने के बाद ही व्यापक रूप से लागू करें।

## Control UI लैब्स

Control UI स्विच वाले प्रयोगों को प्रबंधित करने के लिए **Settings → Agents & Tools → Labs** खोलें। किसी लैब को सक्षम या अक्षम करने पर प्रामाणिक Gateway
कॉन्फ़िगरेशन तुरंत संशोधित हो जाता है; पृष्ठ केवल तभी पुनः आरंभ करने का संकेत दिखाता
है, जब किसी सुविधा को इसकी आवश्यकता होती है।

Code Mode और Swarm वर्तमान में जारी की गई Labs प्रविष्टियाँ हैं। दोनों स्विच
मौजूदा सत्यापित कॉन्फ़िगरेशन कुंजियाँ लिखते हैं और सामान्यतः Gateway को पुनः आरंभ किए बिना भविष्य के एजेंट
रन पर प्रभावी होते हैं।

## स्थानीय मॉडल लीन मोड

`agents.defaults.experimental.localModelLean: true` प्रत्येक चरण में एजेंट की प्रत्यक्ष सतह से भारी वैकल्पिक टूल हटा देता है: `browser`, `cron`, `message`, `image_generate`, `music_generate`, `video_generate`, `tts`, और `pdf`। स्पष्ट रूप से अनुमत या डिलीवरी के लिए आवश्यक टूल उपलब्ध रहते हैं, हालाँकि Tool Search उन्हें सीधे उपलब्ध कराने के बजाय सूचीबद्ध कर सकता है। जब `tools.toolSearch` पहले से सेट न हो, तब लीन मोड Plugin/MCP/क्लाइंट कैटलॉग के लिए भी संरचित Tool Search (`tool_search`, `tool_describe`, `tool_call`) को डिफ़ॉल्ट बनाता है। इसे किसी एक एजेंट तक सीमित करने के लिए `agents.entries.*.experimental.localModelLean` का उपयोग करें।

ऑनबोर्डिंग के दौरान, सत्यापित `ollama` या `lmstudio` इन्फ़रेंस रूट, मान अनुपस्थित होने पर, स्वचालित रूप से `agents.defaults.experimental.localModelLean: true` सेट करता है। OpenClaw दर्ज करता है कि यह सेटिंग ऑनबोर्डिंग से आई है, इसलिए बाद में सत्यापित गैर-स्थानीय रूट केवल स्वचालित सेटिंग को हटाता है। स्पष्ट रूप से कॉन्फ़िगर किया गया `true` या `false` सुरक्षित रखा जाता है। अन्य स्वयं-होस्टेड और OpenAI-संगत प्रदाताओं का अनुमान मॉडल नामों या URL से नहीं लगाया जाता।

यदि आपने Tool Search को पहले से वैश्विक रूप से समायोजित किया है, तो OpenClaw उस कॉन्फ़िगरेशन को अपरिवर्तित छोड़ता है। लीन-मोड Tool Search डिफ़ॉल्ट से बाहर निकलने के लिए `tools.toolSearch: false` सेट करें।

संरचित `tools` मोड में, लीन रन `exec` को Tool Search नियंत्रणों के साथ सीधे दृश्यमान रखते हैं, ताकि कोडिंग के लिए समायोजित स्थानीय मॉडल अब भी अपना परिचित शेल मार्ग चुन सकें। इससे केवल स्कीमा की दृश्यता बदलती है: सामान्य टूल नीति, सैंडबॉक्सिंग और exec अनुमोदन अब भी लागू होते हैं। स्पष्ट `code` और `directory` मोड अपना सामान्य Compaction व्यवहार बनाए रखते हैं।

### ये टूल क्यों

इन टूल के विवरण सबसे बड़े, पैरामीटर संरचनाएँ सबसे व्यापक, या किसी छोटे मॉडल को सामान्य कोडिंग और वार्तालाप मार्ग से भटकाने की संभावना सबसे अधिक होती है। छोटे कॉन्टेक्स्ट वाले या अधिक सख़्त OpenAI-संगत बैकएंड पर यही निम्न के बीच अंतर बनता है:

- टूल स्कीमा का प्रॉम्प्ट में समा जाना बनाम वार्तालाप इतिहास को बाहर कर देना।
- मॉडल का सही टूल चुनना बनाम बहुत अधिक समान स्कीमा के कारण विकृत टूल कॉल उत्पन्न करना।
- Chat Completions अडैप्टर का संरचित-आउटपुट सीमाओं के भीतर रहना बनाम टूल-कॉल पेलोड आकार के कारण 400 त्रुटि मिलना।

उन्हें हटाने से केवल प्रत्यक्ष टूल सूची छोटी होती है। मॉडल के पास अब भी `read`, `write`, `edit`, `exec`, `apply_patch`, छवि समझ, वेब खोज/फ़ेच (कॉन्फ़िगर होने पर), मेमोरी और सत्र/एजेंट टूल होते हैं। अतिरिक्त कैटलॉग Tool Search के माध्यम से उपलब्ध रहते हैं, जब तक आप `tools.toolSearch: false` सेट न करें; स्पष्ट टूल अनुमतियाँ किसी लीन एजेंट को सीमित वर्कफ़्लो में फिर से शामिल कर सकती हैं।

### इसे कब चालू करें

लीन मोड तब सक्षम करें, जब आपने सिद्ध कर लिया हो कि मॉडल Gateway से संचार कर सकता है, लेकिन एजेंट के पूर्ण चरण अनुचित व्यवहार करते हैं:

1. `openclaw infer model run --gateway --model <ref> --prompt "Reply with exactly: pong"` सफल होता है।
2. सामान्य एजेंट चरण विकृत टूल कॉल, अत्यधिक बड़े प्रॉम्प्ट, या मॉडल द्वारा अपने टूल की उपेक्षा के कारण विफल होता है।
3. `localModelLean: true` को टॉगल करने से विफलता दूर हो जाती है।

### इसे कब बंद रखें

यदि आपका बैकएंड संपूर्ण डिफ़ॉल्ट रनटाइम को ठीक से संभालता है, तो इसे बंद रखें। यह उन स्थानीय स्टैक के लिए वैकल्पिक उपाय है जिन्हें छोटी टूल सतह की आवश्यकता होती है, न कि होस्टेड मॉडल या पर्याप्त संसाधनों वाले स्थानीय सिस्टम के लिए डिफ़ॉल्ट।

लीन मोड `tools.profile`, `tools.allow`/`tools.deny`, या मॉडल के `compat.supportsTools: false` बचाव विकल्प को प्रतिस्थापित नहीं करता। किसी विशिष्ट एजेंट के लिए स्थायी रूप से संकरी टूल सतह हेतु उन स्थिर नियंत्रणों को प्राथमिकता दें।

### सक्षम करें

```json5
{
  agents: {
    defaults: {
      experimental: {
        localModelLean: true,
      },
    },
  },
}
```

केवल एक एजेंट के लिए:

```json5
{
  agents: {
    list: [
      {
        id: "local",
        model: "lmstudio/gemma-4-e4b-it",
        experimental: {
          localModelLean: true,
        },
      },
    ],
  },
}
```

फ़्लैग बदलने के बाद Gateway को पुनः आरंभ करें। लीन फ़िल्टरिंग `browser`, `cron`, `message`, `image_generate`, `music_generate`, `video_generate`, `tts`, और `pdf` को हटा देती है, जब तक आप उन्हें `tools.allow` या `tools.alsoAllow` के साथ स्पष्ट रूप से सुरक्षित न रखें; Tool Search सुरक्षित रखे गए टूल को सीधे उपलब्ध कराने के बजाय अब भी सूचीबद्ध कर सकता है।

## प्रायोगिक का अर्थ छिपा हुआ नहीं है

किसी प्रायोगिक सुविधा को दस्तावेज़ों और स्वयं कॉन्फ़िगरेशन पथ में स्पष्ट रूप से ऐसा बताया जाना चाहिए, न कि स्थिर दिखने वाले डिफ़ॉल्ट नियंत्रण के पीछे छिपाया जाना चाहिए।
