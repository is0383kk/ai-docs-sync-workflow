[Honcho](https://honcho.dev) एक बाहरी Plugin के माध्यम से OpenClaw में AI-मूल मेमोरी जोड़ता है। यह वार्तालापों को एक समर्पित सेवा में बनाए रखता है और समय के साथ उपयोगकर्ता तथा एजेंट मॉडल तैयार करता है, जिससे आपके एजेंट को कार्यक्षेत्र की Markdown फ़ाइलों से आगे जाने वाला क्रॉस-सेशन संदर्भ मिलता है।

## यह क्या प्रदान करता है

- **क्रॉस-सेशन मेमोरी** - प्रत्येक संवाद के बाद वार्तालाप बने रहते हैं, इसलिए संदर्भ सेशन रीसेट, Compaction और चैनल बदलने पर भी बना रहता है।
- **उपयोगकर्ता मॉडलिंग** - Honcho प्रत्येक उपयोगकर्ता के लिए एक प्रोफ़ाइल (प्राथमिकताएँ, तथ्य, संचार शैली) और एजेंट के लिए एक प्रोफ़ाइल (व्यक्तित्व, सीखे गए व्यवहार) बनाए रखता है।
- **सिमेंटिक खोज** - केवल वर्तमान सेशन में ही नहीं, बल्कि पिछले वार्तालापों के अवलोकनों में भी खोज करता है।
- **मल्टी-एजेंट जागरूकता** - पैरेंट एजेंट स्वतः बनाए गए सब-एजेंटों को ट्रैक करते हैं और चाइल्ड सेशन में पैरेंट को पर्यवेक्षक के रूप में जोड़ा जाता है।

## उपलब्ध टूल

Honcho ऐसे टूल पंजीकृत करता है जिनका उपयोग एजेंट वार्तालाप के दौरान कर सकता है:

**डेटा पुनर्प्राप्ति (तेज़, कोई LLM कॉल नहीं):**

| टूल                        | यह क्या करता है                                           |
| --------------------------- | ------------------------------------------------------ |
| `honcho_context`            | सभी सेशन में उपयोगकर्ता का पूर्ण निरूपण               |
| `honcho_search_conclusions` | संग्रहीत निष्कर्षों में सिमेंटिक खोज                |
| `honcho_search_messages`    | सभी सेशन में संदेश खोजें (प्रेषक, तारीख के अनुसार फ़िल्टर करें) |
| `honcho_session`            | वर्तमान सेशन का इतिहास और सारांश                    |

**प्रश्नोत्तर (LLM-संचालित):**

| टूल         | यह क्या करता है                                                              |
| ------------ | ------------------------------------------------------------------------- |
| `honcho_ask` | उपयोगकर्ता के बारे में पूछें। तथ्यों के लिए `depth='quick'`, संश्लेषण के लिए `'thorough'` |

## आरंभ करना

Plugin इंस्टॉल करें और सेटअप चलाएँ:

```bash
openclaw plugins install @honcho-ai/openclaw-honcho
openclaw honcho setup
openclaw gateway --force
```

सेटअप कमांड आपके API क्रेडेंशियल माँगता है, कॉन्फ़िग लिखता है और वैकल्पिक रूप से मौजूदा कार्यक्षेत्र मेमोरी फ़ाइलों को माइग्रेट करता है।

<Info>
Honcho को पूरी तरह स्थानीय रूप से (स्वयं होस्ट किया हुआ) या `api.honcho.dev` पर प्रबंधित API के माध्यम से चलाया जा सकता है। स्वयं होस्ट किए गए विकल्प के लिए किसी बाहरी निर्भरता की आवश्यकता नहीं है।
</Info>

## कॉन्फ़िगरेशन

सेटिंग्स `plugins.entries["openclaw-honcho"].config` के अंतर्गत होती हैं:

```json5
{
  plugins: {
    entries: {
      "openclaw-honcho": {
        config: {
          apiKey: "your-api-key", // स्वयं होस्ट किए गए विकल्प के लिए छोड़ दें
          workspaceId: "openclaw", // मेमोरी पृथक्करण
          baseUrl: "https://api.honcho.dev",
        },
      },
    },
  },
}
```

स्वयं होस्ट किए गए इंस्टेंस के लिए, `baseUrl` को अपने स्थानीय सर्वर की ओर इंगित करें (उदाहरण के लिए `http://localhost:8000`) और API कुंजी छोड़ दें।

## मौजूदा मेमोरी माइग्रेट करना

यदि आपके पास मौजूदा कार्यक्षेत्र मेमोरी फ़ाइलें (`USER.md`, `MEMORY.md`, `IDENTITY.md`, `memory/`, `canvas/`) हैं, तो `openclaw honcho setup` उनका पता लगाता है और उन्हें माइग्रेट करने का विकल्प देता है।

<Info>
माइग्रेशन गैर-विनाशकारी है - फ़ाइलें Honcho पर अपलोड की जाती हैं। मूल फ़ाइलों को कभी हटाया या स्थानांतरित नहीं किया जाता।
</Info>

## यह कैसे काम करता है

AI के प्रत्येक संवाद के बाद, वार्तालाप Honcho में बनाए रखा जाता है। उपयोगकर्ता और एजेंट, दोनों के संदेशों का अवलोकन किया जाता है, जिससे Honcho समय के साथ अपने मॉडल तैयार और परिष्कृत कर पाता है।

वार्तालाप के दौरान, Honcho टूल OpenClaw के `before_prompt_build` Plugin हुक के दौरान सेवा को क्वेरी करते हैं और मॉडल द्वारा प्रॉम्प्ट देखने से पहले प्रासंगिक संदर्भ सम्मिलित करते हैं।

## Honcho बनाम अंतर्निहित मेमोरी

|                   | अंतर्निहित / QMD                | Honcho                              |
| ----------------- | ---------------------------- | ----------------------------------- |
| **संग्रहण**       | कार्यक्षेत्र Markdown फ़ाइलें     | समर्पित सेवा (स्थानीय या होस्ट की गई) |
| **क्रॉस-सेशन** | मेमोरी फ़ाइलों के माध्यम से             | स्वचालित, अंतर्निहित                 |
| **उपयोगकर्ता मॉडलिंग** | मैन्युअल (MEMORY.md में लिखें)  | स्वचालित प्रोफ़ाइल                  |
| **खोज**        | वेक्टर + कीवर्ड (हाइब्रिड)    | अवलोकनों पर सिमेंटिक खोज          |
| **मल्टी-एजेंट**   | ट्रैक नहीं किया जाता                  | पैरेंट/चाइल्ड जागरूकता              |
| **निर्भरताएँ**  | कोई नहीं (अंतर्निहित) या QMD बाइनरी | Plugin इंस्टॉलेशन                      |

Honcho और अंतर्निहित मेमोरी सिस्टम साथ मिलकर काम कर सकते हैं। QMD कॉन्फ़िगर होने पर, Honcho की क्रॉस-सेशन मेमोरी के साथ स्थानीय Markdown फ़ाइलों में खोज करने के लिए अतिरिक्त टूल उपलब्ध हो जाते हैं।

## CLI कमांड

```bash
openclaw honcho setup                        # API कुंजी कॉन्फ़िगर करें और फ़ाइलें माइग्रेट करें
openclaw honcho status                       # कनेक्शन की स्थिति जाँचें
openclaw honcho ask <question>               # उपयोगकर्ता के बारे में Honcho से क्वेरी करें
openclaw honcho search <query> [-k N] [-d D] # मेमोरी में सिमेंटिक खोज
```
