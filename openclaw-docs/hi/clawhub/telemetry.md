# टेलीमेट्री

ClawHub समग्र Skills और Plugin इंस्टॉल की संख्या की गणना करने के लिए न्यूनतम CLI टेलीमेट्री का उपयोग करता है।

## टेलीमेट्री कब एकत्र की जाती है

टेलीमेट्री केवल तभी भेजी जाती है जब:

- आप CLI में लॉग इन हों।
- आप `clawhub install <slug>` चलाएँ, या प्रमाणीकृत
  `openclaw plugins install clawhub:<package>` इंस्टॉल पूरा करें।
- टेलीमेट्री **अक्षम न हो** (नीचे “अक्षम करने का तरीका” देखें)।

यदि आप लॉग इन नहीं हैं, तो कुछ भी रिपोर्ट नहीं किया जाता।

## हम क्या एकत्र करते हैं

किसी Skill या Plugin के इंस्टॉल हो जाने और उसके स्थानीय इंस्टॉल रिकॉर्ड के स्थायी रूप से सहेजे जाने के बाद, CLI
सर्वोत्तम प्रयास के आधार पर एक इंस्टॉल इवेंट भेजता है।

इवेंट में शामिल हैं:

- इंस्टॉल किए गए Skill का स्लग या Plugin के पैकेज का प्रामाणिक नाम।
- `version`: ज्ञात होने पर इंस्टॉल किया गया संस्करण।

### हम क्या एकत्र _नहीं_ करते

- कोई फ़ोल्डर पथ या फ़ोल्डर से प्राप्त पहचानकर्ता नहीं।
- फ़ाइलों की कोई सामग्री नहीं।
- हर रन के लॉग, प्रॉम्प्ट या अन्य CLI आउटपुट नहीं।

## इंस्टॉल की संख्या

Skills के लिए, ClawHub इनका रखरखाव करता है:

- `installsAllTime`: वे विशिष्ट उपयोगकर्ता जिन्होंने Skill के लिए कम-से-कम एक CLI इंस्टॉल की रिपोर्ट की है।
- `installsCurrent`: वे विशिष्ट उपयोगकर्ता जिन्होंने किसी इंस्टॉल की रिपोर्ट की है और अपनी
  टेलीमेट्री नहीं हटाई है।

Plugins के लिए, ClawHub प्रत्येक उपयोगकर्ता और पैकेज द्वारा रिपोर्ट किए गए पहले सफल इंस्टॉल की गणना करता है।
बार-बार किए गए इंस्टॉल और अपडेट, समग्र इंस्टॉल संख्या बढ़ाए बिना रिकॉर्ड किए गए संस्करण को रीफ़्रेश करते हैं।

## पारदर्शिता + उपयोगकर्ता नियंत्रण

सभी को केवल **समेकित इंस्टॉल काउंटर** दिखाई देते हैं।

आपका खाता हटाने से आपका टेलीमेट्री डेटा भी हट जाता है और इंस्टॉल
काउंटर में उसका योगदान निकाल दिया जाता है।

## टेलीमेट्री अक्षम करने का तरीका

यह पर्यावरण चर सेट करें:

```bash
export CLAWHUB_DISABLE_TELEMETRY=1
```

इसे सेट करने पर CLI इंस्टॉल टेलीमेट्री नहीं भेजेगा।
