# HealthKit सारांश

OpenClaw कनेक्ट किए गए iPhone या iPad Node से वर्तमान कैलेंडर दिवस का केवल-पढ़ने योग्य सारांश अनुरोध कर सकता है। डिवाइस पर ही समुच्चय की गणना की जाती है और केवल कदमों की संख्या, नींद की अवधि, औसत विश्राम हृदय गति और वर्कआउट की संख्या/अवधि लौटाई जाती है। अलग-अलग HealthKit नमूने, स्रोत, मेटाडेटा, क्लिनिकल रिकॉर्ड, पृष्ठभूमि में अंतर्ग्रहण और लेखन समर्थित नहीं हैं।

यह सुविधा डिफ़ॉल्ट रूप से बंद रहती है। इसके लिए iOS डिवाइस पर अलग से सहमति और Gateway पर प्राधिकरण आवश्यक है।

## आवश्यकताएँ

- OpenClaw iOS ऐप चलाने वाला ऐसा iPhone या iPad, जहाँ HealthKit स्वास्थ्य डेटा उपलब्ध होने की रिपोर्ट करता हो।
- कनेक्ट और स्वीकृत iOS Node। [iOS ऐप सेटअप](/hi/platforms/ios) देखें।
- ऐसा वर्तमान Gateway जो iOS Node तक पहुँच सकता हो।
- उन सभी मेट्रिक्स के लिए पठनीय Health डेटा जिन्हें आप देखना चाहते हैं। Apple Watch, Apple Health स्टोर में डेटा जोड़ सकती है, लेकिन HealthKit सारांशों के लिए OpenClaw watchOS ऐप आवश्यक नहीं है।

## पहुँच सक्षम करें

### 1. Gateway कमांड को प्राधिकृत करें

`openclaw.json` में मौजूदा `gateway.nodes.commands.allow` ऐरे में `health.summary` जोड़ें। पहले से मौजूद सभी कमांड सुरक्षित रखें:

```json5
{
  gateway: {
    nodes: {
      commands: { allow: ["health.summary"] },
    },
  },
}
```

`health.summary` को अत्यधिक गोपनीयता-संवेदनशील के रूप में वर्गीकृत किया गया है और iOS प्लेटफ़ॉर्म के डिफ़ॉल्ट द्वारा इसे कभी अनुमति नहीं दी जाती। `gateway.nodes.commands.deny` में मौजूद प्रविष्टि, अनुमति वाली प्रविष्टि को ओवरराइड करती है। [Node कमांड नीति](/hi/nodes#command-policy) देखें।

### 2. iOS डिवाइस पर साझाकरण सक्षम करें

iOS ऐप में:

1. **Settings -> Permissions** खोलें और हमेशा दिखाई देने वाले **Apple Health** अनुभाग में **Apple Health Summaries** खोजें।
2. **Enable Apple Health Summaries** पर टैप करें।
3. प्रकटीकरण पढ़ें, फिर Apple की अनुमति शीट में चुनें कि OpenClaw किन Health श्रेणियों को पढ़ सकता है।

स्विच आपके स्पष्ट OpenClaw साझाकरण विकल्प को रिकॉर्ड करता है। यह दावा नहीं करता कि Apple ने अनुरोध की गई प्रत्येक श्रेणी की अनुमति दे दी है।

Health सारांश सक्षम करने पर Node की घोषित कमांड सतह में `health.summary` जुड़ जाता है। इसके परिणामस्वरूप होने वाले Node पेयरिंग अपडेट को स्वीकृत करें:

```bash
openclaw nodes pending
openclaw nodes approve <requestId>
```

फिर सत्यापित करें कि कनेक्ट किया गया iOS डिवाइस प्रभावी `health.summary` कमांड उपलब्ध कराता है:

```bash
openclaw nodes describe --node "<iOS device name>"
```

## आज का सारांश अनुरोध करें

केवल `today` समर्थित है। यह iOS डिवाइस के वर्तमान कैलेंडर और समय क्षेत्र का उपयोग करके स्थानीय मध्यरात्रि से अनुरोध के समय तक की अवधि को शामिल करता है।

```bash
openclaw nodes invoke \
  --node "<iOS device name>" \
  --command health.summary \
  --params '{"period":"today"}' \
  --json
```

एजेंट `nodes` टूल से भी इसी कमांड को कॉल कर सकते हैं:

```json
{
  "action": "invoke",
  "node": "<iOS device name>",
  "invokeCommand": "health.summary",
  "invokeParamsJson": "{\"period\":\"today\"}"
}
```

सारांश पेलोड में ये शामिल हैं:

| फ़ील्ड                    | अर्थ                                       |
| ------------------------ | --------------------------------------------- |
| `period`                 | हमेशा `today`                                |
| `startISO`               | दिन की स्थानीय शुरुआत, ISO इंस्टैंट के रूप में एन्कोड की गई |
| `endISO`                 | अनुरोध का समय, ISO इंस्टैंट के रूप में एन्कोड किया गया       |
| `timeZoneIdentifier`     | iOS डिवाइस का समय-क्षेत्र पहचानकर्ता               |
| `stepCount`              | पूर्णांकित संचयी कदम                      |
| `sleepDurationMinutes`   | डुप्लिकेट हटाकर निकाला गया सोने का समय, आज तक सीमित    |
| `restingHeartRateBpm`    | औसत विश्राम हृदय गति                    |
| `workoutCount`           | आज शुरू हुए वर्कआउट                   |
| `workoutDurationMinutes` | उन वर्कआउट की कुल अवधि              |

मेट्रिक फ़ील्ड वैकल्पिक हैं और जब HealthKit कोई पठनीय मान नहीं लौटाता, तो उन्हें छोड़ दिया जाता है। अवधि की गणना से पहले नींद के चरणों और ओवरलैप करने वाले स्रोतों को मर्ज किया जाता है, इसलिए एक ही मिनट की गणना दो बार नहीं होती।

## गोपनीयता व्यवहार

- समुच्चयन iOS डिवाइस पर होता है। कच्चे नमूने डिवाइस से बाहर नहीं जाते।
- अनुरोध किया गया समुच्चय आपके Gateway के माध्यम से डिवाइस से बाहर जाता है। जब कोई एजेंट इसका अनुरोध करता है, तो समुच्चय कॉन्फ़िगर किए गए AI प्रदाता तक पहुँचता है और चैट इतिहास में रह सकता है। प्रत्यक्ष CLI आह्वान इसे CLI ऑपरेटर को लौटाता है।
- OpenClaw केवल पढ़ने की पहुँच का अनुरोध करता है। यह Health डेटा जोड़ या संशोधित नहीं कर सकता।
- OpenClaw केवल `health.summary` आह्वान किए जाने पर HealthKit पढ़ता है। पृष्ठभूमि में स्वास्थ्य डेटा अंतर्ग्रहण नहीं होता।
- HealthKit जानबूझकर यह प्रकट नहीं करता कि पढ़ने की पहुँच अस्वीकार की गई थी या नहीं। किसी मेट्रिक के अनुपस्थित होने का अर्थ पहुँच अस्वीकृत होना, मेल खाते नमूनों का न होना या डेटा प्रकार का अनुपलब्ध होना हो सकता है। OpenClaw इन स्थितियों में अंतर नहीं कर सकता।
- यह सारांश व्यक्तिगत स्वास्थ्य और फ़िटनेस संदर्भ के लिए है, निदान या चिकित्सकीय सलाह के लिए नहीं।

साझाकरण रोकने के लिए **Apple Health Summaries** पर वापस जाएँ और **Turn Off Summaries** पर टैप करें। इसके बाद iOS डिवाइस अपने Node की सतह से Health क्षमता और `health.summary` कमांड हटा देता है। Gateway की ओर से गेट बंद करने के लिए आप `gateway.nodes.commands.allow` से `health.summary` भी हटा सकते हैं।

## समस्या निवारण

### कमांड Node द्वारा घोषित नहीं है

पुष्टि करें कि iOS ऐप में Apple Health सारांश सक्षम हैं और डिवाइस कनेक्ट है। `openclaw nodes pending` चलाएँ और किसी भी क्षमता अपडेट को स्वीकृत करें, फिर `openclaw nodes describe --node "<iOS device name>"` का दोबारा निरीक्षण करें।

### कमांड के लिए स्पष्ट ऑप्ट-इन आवश्यक है

`gateway.nodes.commands.allow` में `health.summary` जोड़ें। यह भी जाँचें कि `gateway.nodes.commands.deny` में यह शामिल न हो; अस्वीकृति सूची को प्राथमिकता मिलती है।

### `HEALTH_ACCESS_DISABLED`

ऐप की ओर वाला साझाकरण स्विच बंद है। iOS डिवाइस पर **Settings -> Permissions -> Apple Health** के अंतर्गत **Apple Health Summaries** सक्षम करें।

### सारांश सफल है लेकिन मेट्रिक्स अनुपस्थित हैं

Apple का Health ऐप खोलें और पुष्टि करें कि आज का डेटा मौजूद है। Apple की Health सेटिंग में OpenClaw की पहुँच की समीक्षा करें, लेकिन खाली परिणाम को पहुँच अस्वीकार किए जाने का प्रमाण न मानें: HealthKit जानबूझकर इस अंतर को छिपाता है।

### पुरानी अवधियाँ विफल होती हैं

कमांड केवल `{"period":"today"}` स्वीकार करता है। एकाधिक दिनों और ऐतिहासिक सारांश समर्थित नहीं हैं।
