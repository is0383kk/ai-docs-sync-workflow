ट्रैजेक्टरी कैप्चर OpenClaw का प्रति-सत्र फ़्लाइट रिकॉर्डर है। यह प्रत्येक एजेंट रन के लिए
एक संरचित समयरेखा रिकॉर्ड करता है, फिर `/export-trajectory` वर्तमान सत्र को
एक संशोधित समर्थन बंडल में पैकेज करता है, जिसमें ये शामिल होते हैं:

- मॉडल को भेजा गया प्रॉम्प्ट, सिस्टम प्रॉम्प्ट और टूल
- किन ट्रांसक्रिप्ट संदेशों और टूल कॉल से उत्तर प्राप्त हुआ
- रन का समय समाप्त हुआ, उसे निरस्त किया गया, उसका Compaction हुआ या प्रदाता त्रुटि आई
- कौन-सा मॉडल, plugins, skills और रनटाइम सेटिंग सक्रिय थीं
- प्रदाता द्वारा लौटाया गया उपयोग और प्रॉम्प्ट-कैश मेटाडेटा

व्यापक Gateway समर्थन रिपोर्ट के लिए, इसके बजाय
[`/diagnostics`](/hi/gateway/diagnostics#chat-command) से शुरू करें; यह
सैनिटाइज़ किया गया Gateway बंडल एकत्र करता है और OpenAI Codex हार्नेस सत्रों के लिए, स्वीकृति के
बाद Codex फ़ीडबैक OpenAI को भेज सकता है। जब आपको विस्तृत प्रति-सत्र
प्रॉम्प्ट, टूल और ट्रांसक्रिप्ट समयरेखा चाहिए, तो `/export-trajectory` का उपयोग करें।

## त्वरित शुरुआत

सक्रिय सत्र में भेजें (उपनाम `/trajectory`):

```text
/export-trajectory
```

OpenClaw बंडल को वर्कस्पेस के अंतर्गत लिखता है:

```text
.openclaw/trajectory-exports/openclaw-trajectory-<session>-<timestamp>/
```

इसे ओवरराइड करने के लिए सापेक्ष आउटपुट डायरेक्टरी नाम दें:

```text
/export-trajectory bug-1234
```

नाम `.openclaw/trajectory-exports/` के अंदर रिज़ॉल्व होता है। निरपेक्ष पथ और
`~` पथ अस्वीकार किए जाते हैं।

ट्रैजेक्टरी बंडल में प्रॉम्प्ट, मॉडल संदेश, टूल स्कीमा, टूल
परिणाम, रनटाइम इवेंट और स्थानीय पथ हो सकते हैं, इसलिए चैट कमांड हमेशा
exec स्वीकृति से होकर चलता है। जब आप बंडल बनाना चाहते हों, तो निर्यात को एक बार
स्वीकृत करें; सभी को अनुमति देने वाले विकल्प का उपयोग न करें। समूह चैट में, OpenClaw साझा कक्ष में
ट्रैजेक्टरी विवरण पोस्ट करने के बजाय स्वीकृति
प्रॉम्प्ट और निर्यात परिणाम निजी रूप से स्वामी को भेजता है।

स्थानीय निरीक्षण या समर्थन वर्कफ़्लो के लिए, अंतर्निहित CLI कमांड
सीधे चलाएँ:

```bash
openclaw sessions export-trajectory --session-key "agent:main:telegram:direct:123" --workspace .
```

अन्य फ़्लैग: `--output <path>` (`.openclaw/trajectory-exports` के अंदर डायरेक्टरी नाम),
`--store <path>` (सत्र स्टोर ओवरराइड),
`--agent <id>` (स्टोर रिज़ॉल्यूशन के लिए एजेंट आईडी), `--json` (संरचित आउटपुट)।

## पहुँच

ट्रैजेक्टरी निर्यात स्वामी का कमांड है। प्रेषक को सामान्य कमांड
प्राधिकरण जाँचों के साथ चैनल की स्वामी जाँच भी उत्तीर्ण करनी होगी।

## क्या रिकॉर्ड होता है

OpenClaw एजेंट रन के लिए ट्रैजेक्टरी कैप्चर डिफ़ॉल्ट रूप से चालू रहता है।

रनटाइम इवेंट में ये शामिल हैं:

- `session.started`
- `trace.metadata`
- `context.compiled`
- `prompt.submitted`
- `model.fallback_step`, जिसमें स्रोत मॉडल, अगला मॉडल, विफलता का कारण/विवरण, श्रृंखला की स्थिति और यह कि श्रृंखला आगे बढ़ी, सफल हुई या समाप्त हो गई, शामिल हैं
- `model.completed`
- `trace.artifacts`
- `session.ended`

ट्रांसक्रिप्ट इवेंट सक्रिय सत्र शाखा से पुनर्निर्मित किए जाते हैं: उपयोगकर्ता
संदेश, सहायक संदेश, टूल कॉल, टूल परिणाम, Compaction, मॉडल
परिवर्तन, लेबल और कस्टम सत्र प्रविष्टियाँ।

इवेंट इस स्कीमा मार्कर के साथ JSON Lines के रूप में लिखे जाते हैं:

```json
{
  "traceSchema": "openclaw-trajectory",
  "schemaVersion": 1
}
```

## बंडल फ़ाइलें

| फ़ाइल                  | सामग्री                                                                                       |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| `manifest.json`       | बंडल स्कीमा, स्रोत फ़ाइलें, इवेंट की संख्या और जनरेट की गई फ़ाइलों की सूची                             |
| `events.jsonl`        | क्रमबद्ध रनटाइम और ट्रांसक्रिप्ट समयरेखा                                                        |
| `session-branch.json` | संशोधित सक्रिय ट्रांसक्रिप्ट शाखा और सत्र हेडर                                           |
| `metadata.json`       | OpenClaw संस्करण, OS/रनटाइम, मॉडल, कॉन्फ़िग स्नैपशॉट, plugins, skills और प्रॉम्प्ट मेटाडेटा     |
| `artifacts.json`      | अंतिम स्थिति, त्रुटियाँ, उपयोग, प्रॉम्प्ट कैश, Compaction की संख्या, सहायक टेक्स्ट और टूल मेटाडेटा |
| `prompts.json`        | सबमिट किए गए प्रॉम्प्ट और चुने गए प्रॉम्प्ट-निर्माण विवरण                                         |
| `system-prompt.txt`   | नवीनतम संकलित सिस्टम प्रॉम्प्ट, यदि कैप्चर किया गया हो                                                   |
| `tools.json`          | मॉडल को भेजी गई टूल परिभाषाएँ, यदि कैप्चर की गई हों                                              |

`manifest.json` किसी दिए गए बंडल में मौजूद फ़ाइलों को सूचीबद्ध करता है; जब सत्र ने
संबंधित रनटाइम डेटा कैप्चर नहीं किया हो, तो कुछ फ़ाइलें
छोड़ दी जाती हैं।

## कैप्चर स्टोरेज

रनटाइम ट्रैजेक्टरी इवेंट सत्र के साथ प्रति-एजेंट SQLite
डेटाबेस में संग्रहीत किए जाते हैं। ट्रैजेक्टरी निर्यात करने पर एक संशोधित JSONL समर्थन बंडल तैयार होता है;
लाइव रनटाइम कैप्चर सत्र के पास स्थित JSONL साइडकार नहीं है।

पुराने रिलीज़ या स्पष्ट लेगेसी-फ़ाइल निर्यातों से लेगेसी `.trajectory.jsonl` और
`.trajectory-path.json` फ़ाइलें अब भी दिखाई दे सकती हैं। सत्र रखरखाव
उन फ़ाइलों को सफ़ाई लक्ष्य मानता है; सक्रिय कैप्चर डेटाबेस पंक्तियाँ लिखता है।

## कैप्चर अक्षम करना

```bash
export OPENCLAW_TRAJECTORY=0
```

यह OpenClaw शुरू करने से पहले रनटाइम ट्रैजेक्टरी कैप्चर अक्षम करता है।
`/export-trajectory` अब भी ट्रांसक्रिप्ट शाखा निर्यात कर सकता है, लेकिन केवल रनटाइम से जुड़ा
डेटा, जैसे संकलित संदर्भ, प्रदाता आर्टिफ़ैक्ट और प्रॉम्प्ट मेटाडेटा,
गायब हो सकता है।

## फ़्लश टाइमआउट समायोजित करना

OpenClaw एजेंट क्लीनअप के दौरान रनटाइम ट्रैजेक्टरी पंक्तियाँ फ़्लश करता है। डिफ़ॉल्ट
क्लीनअप टाइमआउट 10,000 ms है। धीमी डिस्क या बड़े स्टोर पर, OpenClaw शुरू करने से
पहले `OPENCLAW_TRAJECTORY_FLUSH_TIMEOUT_MS` सेट करें:

```bash
export OPENCLAW_TRAJECTORY_FLUSH_TIMEOUT_MS=30000
```

यह नियंत्रित करता है कि OpenClaw कब `openclaw-trajectory-flush` टाइमआउट लॉग करके
आगे बढ़ता है; यह ट्रैजेक्टरी की आकार सीमाएँ नहीं बदलता। उन सभी एजेंट
क्लीनअप चरणों को समायोजित करने के लिए, जो स्पष्ट टाइमआउट नहीं देते,
`OPENCLAW_AGENT_CLEANUP_TIMEOUT_MS` सेट करें।

## गोपनीयता और सीमाएँ

ट्रैजेक्टरी बंडल समर्थन और डीबगिंग के लिए हैं, सार्वजनिक रूप से पोस्ट करने के लिए नहीं। OpenClaw
निर्यात फ़ाइलें लिखने से पहले संवेदनशील मान संशोधित करता है:

- क्रेडेंशियल और ज्ञात सीक्रेट-जैसे पेलोड फ़ील्ड
- इमेज डेटा
- स्थानीय स्टेट पथ
- वर्कस्पेस पथ, जिन्हें `$WORKSPACE_DIR` से बदल दिया जाता है
- होम डायरेक्टरी पथ, जहाँ उनका पता चलता है

निर्यातक इनपुट आकार भी सीमित करता है:

- रनटाइम कैप्चर: लाइव कैप्चर 10 MiB तक सीमित एक रोलिंग विंडो है, जो नए इवेंट के लिए जगह बनाने हेतु सबसे पुराने इवेंट हटा देती है; निर्यात मौजूदा लेगेसी रनटाइम साइडकार फ़ाइलों को 50 MiB तक स्वीकार करता है
- सत्र फ़ाइलें: 50 MiB
- प्रति निर्यात रनटाइम इवेंट: 200,000
- कुल निर्यात किए गए इवेंट: 250,000
- व्यक्तिगत रनटाइम इवेंट पंक्तियाँ 256 KiB से अधिक होने पर काट दी जाती हैं

बंडल को अपनी टीम के बाहर साझा करने से पहले उनकी समीक्षा करें। संशोधन सर्वोत्तम-प्रयास
पर आधारित है और प्रत्येक एप्लिकेशन-विशिष्ट सीक्रेट को नहीं पहचान सकता।

## समस्या निवारण

यदि निर्यात में कोई रनटाइम इवेंट नहीं है:

- पुष्टि करें कि OpenClaw को `OPENCLAW_TRAJECTORY=0` के बिना शुरू किया गया था
- सत्र में एक और संदेश चलाएँ, फिर दोबारा निर्यात करें
- `runtimeEventCount` के लिए `manifest.json` का निरीक्षण करें

यदि कमांड आउटपुट पथ को अस्वीकार करता है:

- `bug-1234` जैसा सापेक्ष नाम उपयोग करें
- `/tmp/...` या `~/...` न दें
- निर्यात को `.openclaw/trajectory-exports/` के अंदर रखें

यदि निर्यात आकार त्रुटि के साथ विफल होता है, तो सत्र या साइडकार ने ऊपर दी गई
निर्यात सुरक्षा सीमाएँ पार कर दी हैं। नया सत्र शुरू करें या छोटा
पुनरुत्पादन निर्यात करें।
