GMI Cloud अत्याधुनिक और ओपन-वेट मॉडल के लिए एक होस्टेड इन्फ़रेंस प्लेटफ़ॉर्म है,
जो OpenAI-संगत API के पीछे उपलब्ध है। OpenClaw में यह एक आधिकारिक बाहरी प्रदाता
Plugin है: इसे एक बार इंस्टॉल करें, सामान्य मॉडल प्रमाणीकरण के माध्यम से क्रेडेंशियल सहेजें और
`gmi/google/gemini-3.1-flash-lite` जैसे मॉडल रेफ़रेंस का उपयोग करें।

GMI का उपयोग तब करें, जब आपको GMI के कैटलॉग द्वारा उपलब्ध कराए गए Anthropic,
DeepSeek, Google, Moonshot, OpenAI और Z.AI रूट सहित कई होस्टेड मॉडल फ़ैमिली के लिए
एक API कुंजी चाहिए। यह मॉडल फ़ॉलबैक के लिए द्वितीयक प्रदाता के रूप में, विभिन्न विक्रेताओं के
होस्टेड रूट की तुलना करने के लिए, या जब आपके प्राथमिक प्रदाता से पहले GMI पर कोई मॉडल
उपलब्ध हो, तब उपयोगी है। प्रदाता आईडी, प्रमाणीकरण प्रोफ़ाइल, उपनाम, मॉडल कैटलॉग सीड और
बेस URL का स्वामित्व OpenClaw के पास है; लाइव मॉडल उपलब्धता, बिलिंग, दर सीमाओं और
प्रदाता-पक्ष की किसी भी रूटिंग नीति का स्वामित्व GMI के पास है।

| प्रॉपर्टी      | मान                                    |
| ------------- | ---------------------------------------- |
| प्रदाता आईडी   | `gmi` (उपनाम: `gmi-cloud`, `gmicloud`) |
| पैकेज       | `@openclaw/gmi-provider`                 |
| प्रमाणीकरण एन्वायरनमेंट वेरिएबल  | `GMI_API_KEY`                            |
| API           | OpenAI-संगत (`openai-completions`) |
| बेस URL      | `https://api.gmi-serving.com/v1`         |
| डिफ़ॉल्ट मॉडल | `gmi/google/gemini-3.1-flash-lite`       |

## सेटअप

Plugin इंस्टॉल करें, Gateway को पुनः आरंभ करें और फिर GMI Cloud में एक API कुंजी बनाएँ
(`https://www.gmicloud.ai/`):

```bash
openclaw plugins install @openclaw/gmi-provider
openclaw gateway restart
```

फिर चलाएँ:

```bash
openclaw onboard --auth-choice gmi-api-key
```

गैर-इंटरैक्टिव सेटअप में `--gmi-api-key <key>` दिया जा सकता है, या यह सेट करें:

```bash
export GMI_API_KEY="<your-gmi-api-key>" # pragma: allowlist secret
```

## GMI कब चुनें

- आपको स्थानीय मॉडल सर्वर के बजाय एक होस्टेड OpenAI-संगत एंडपॉइंट चाहिए।
- आप एक प्रदाता खाते के माध्यम से कई व्यावसायिक और ओपन-वेट मॉडल फ़ैमिली आज़माना
  चाहते हैं।
- आपको DeepInfra, OpenRouter, Together या सीधे विक्रेता API से अलग अपस्ट्रीम रूटिंग
  वाला फ़ॉलबैक प्रदाता चाहिए।
- आपको GMI-विशिष्ट मॉडल आईडी, मूल्य निर्धारण या खाता नियंत्रण चाहिए।

जब आपको ऐसी विक्रेता-मूल सुविधाएँ चाहिए जिन्हें GMI अपने OpenAI-संगत रूट के माध्यम से
उपलब्ध नहीं कराता, तो इसके बजाय सीधे विक्रेता प्रदाता को चुनें। जब डेटा स्थानीयता या स्थानीय
GPU नियंत्रण, होस्टेड सुविधा से अधिक महत्वपूर्ण हो, तो LM Studio, Ollama, SGLang या
vLLM जैसे स्थानीय प्रदाता को चुनें।

## मॉडल

Plugin कैटलॉग सामान्यतः उपलब्ध GMI Cloud रूट आईडी को सीड करता है:

| मॉडल रेफ़रेंस                          | इनपुट        | कॉन्टेक्स्ट   | अधिकतम आउटपुट |
| ---------------------------------- | ------------ | --------- | ---------- |
| `gmi/anthropic/claude-sonnet-4.6`  | टेक्स्ट + इमेज | 200,000   | 64,000     |
| `gmi/deepseek-ai/DeepSeek-V3.2`    | टेक्स्ट         | 163,840   | 65,536     |
| `gmi/google/gemini-3.1-flash-lite` | टेक्स्ट + इमेज | 1,048,576 | 65,536     |
| `gmi/moonshotai/Kimi-K2.5`         | टेक्स्ट + इमेज | 262,144   | 65,536     |
| `gmi/openai/gpt-5.4`               | टेक्स्ट + इमेज | 400,000   | 128,000    |
| `gmi/zai-org/GLM-5.1-FP8`          | टेक्स्ट         | 202,752   | 65,536     |

कैटलॉग एक सीड है, यह गारंटी नहीं कि प्रत्येक खाता हर समय प्रत्येक मॉडल को कॉल कर सकता
है। आपके परिवेश में कॉन्फ़िगर किया गया प्रदाता जो मॉडल रिपोर्ट करता है, उन्हें सूचीबद्ध करें:

```bash
openclaw models list --provider gmi
```

## समस्या निवारण

- `401` या `403`: जाँचें कि OpenClaw चलाने वाली प्रक्रिया के लिए `GMI_API_KEY` सेट है,
  या प्रदाता प्रमाणीकरण प्रोफ़ाइल में कुंजी सहेजने के लिए ऑनबोर्डिंग फिर से चलाएँ।
- अज्ञात मॉडल त्रुटियाँ: पुष्टि करें कि मॉडल आपके GMI खाते में मौजूद है और
  `openclaw models list --provider gmi` द्वारा दिखाए गए पूर्ण `gmi/<route-id>` रेफ़रेंस का उपयोग करें।
- रुक-रुककर आने वाली प्रदाता त्रुटियाँ: कोई अलग GMI रूट आज़माएँ या GMI को एकमात्र
  प्राथमिक मॉडल प्रदाता के बजाय फ़ॉलबैक के रूप में कॉन्फ़िगर करें।
