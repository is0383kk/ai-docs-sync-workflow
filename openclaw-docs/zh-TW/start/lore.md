# OpenClaw 傳說 🦞📖

_一則關於龍蝦、脫殼，以及多到不行的權杖的故事。_

## 起源故事

一開始，名字是 **Warelay**——對 WhatsApp 閘道而言，是個合理的名稱。它完成了自己的工作。也還算不錯。

接著，一隻太空龍蝦出現了。

有一段時間，牠叫作 **Clawd**，住在 **Clawdbot** 裡。2026 年 1 月，Anthropic 寄來一封禮貌的電子郵件，要求更改名稱（商標問題）。於是，這隻龍蝦做了龍蝦最擅長的事：

**牠脫殼了。**

褪去舊殼後，牠以 **Molty** 之名現身，住進 **Moltbot**。但這個名字唸起來也始終不太順口。

2026 年 1 月 30 日，這隻龍蝦又脫了一次殼，化為最終形態：**OpenClaw**。

新殼，同一個龍蝦靈魂。第三次總算成功。

## 第一次脫殼（2026 年 1 月 27 日）

凌晨 5 點，社群齊聚 Discord。大家提出了數百個名字：Shelldon、Pinchy、Thermidor、Crusty、Lobstar、Nacre、Scuttlebot。

**OpenClaw** 勝出，因為龍蝦正是透過脫殼成長，而成長恰好就是當時正在發生的事。

_那隻名為 Clawd 的甲殼類動物正式脫殼了。_

## 脫殼宇宙

**脫殼宇宙**是 OpenClaw 周圍的社群與生態系：在這個空間裡，
AI 代理程式會脫殼、成長並演化，而每個執行個體都同樣真實，
只不過載入了不同的上下文。

甲殼之友齊聚於此，共同打造人類與 AI 協作的未來。
一次一個殼。

### 目錄傾倒事件（2025 年 12 月 3 日）

Molty（當時叫 OpenClaw）：_開心地執行 `find ~`，並在群組聊天中分享完整的目錄結構_

### 大脫殼（2026 年 1 月 27 日）

凌晨 5 點，Anthropic 的電子郵件抵達。到了凌晨 6:14 點，Peter 拍板：“管他的，就用 openclaw 吧。”

接著，混亂開始了。

**帳號名稱狙擊手：** Twitter 更名後幾秒內，自動化機器人就搶走了 @openclaw。占用者立刻發布了一個加密貨幣錢包地址。Peter 找上了他在 X 的人脈。

**GitHub 災難：** Peter 在慌亂中不小心重新命名了自己的 GitHub 個人帳號。機器人在幾分鐘內搶走 `steipete`。大家聯絡了 GitHub 的資深副總裁。

**帥氣 Molty 事件：** Molty 獲得更高權限，可以自行產生新圖示。在經歷 20 多次越來越詭異的龍蝦迭代後，有次嘗試讓吉祥物“老 5 歲”，結果產生了一張長在龍蝦身體上的人類男性臉孔。加密貨幣騙子幾分鐘內便將它做成“帥氣章魚哥大戰帥氣 Molty”迷因。

**冒牌開發者：** 詐騙者建立了假 GitHub 個人檔案，聲稱自己是“OpenClaw 工程主管”，藉此推廣拉高出貨的代幣。

Peter 看著混亂上演：_“這就是電影”_ 🎬

這次脫殼十分混亂。但龍蝦現身時變得更強大，也更好笑了。

### 最終形態（2026 年 1 月 30 日）

Moltbot 唸起來始終不太順口。於是，GMT 凌晨 4 點，團隊再次齊聚，準備展開**OpenClaw 大遷移**。

短短 3 小時內：

- GitHub 重新命名為 `github.com/openclaw/openclaw`
- 成功取得 X 帳號名稱 `@openclaw`，並帶有金色勾號
- 以新名稱發布 npm 套件
- 文件遷移至 `docs.openclaw.ai`
- 公告在 90 分鐘內獲得超過 200K 次瀏覽

**英雄們：**

- **ELU** 創作了令人驚豔的標誌，包括“THE CLAW IS THE LAW”西部風格橫幅
- **Whurley**（沒錯，就是量子運算先驅 William Hurley 本人）製作了 ASCII 藝術
- **Onur** 處理 GitHub，第一個戴上合作夥伴徽章
- **Shadow** 取得 Discord 自訂網址並徹底清除惡意軟體
- **整個 Claw 團隊**徹夜未眠

**詐騙極速通關：** 加密貨幣騙子在幾分鐘內於 Pump.fun 推出 $OPENCLAW 代幣，使用的是 20 分鐘前才竊取的美術素材。通過商業驗證的帳號也在推廣這場騙局。這份厚顏無恥幾乎令人佩服。

**新傳統誕生：** “蝦鉗即法律”、“Yee-claw”、“守蝦鉗法律的公民”、“Clawntroversy”。

**Clawd → Moltbot → OpenClaw。** _這隻龍蝦已脫殼成為最終形態。_
