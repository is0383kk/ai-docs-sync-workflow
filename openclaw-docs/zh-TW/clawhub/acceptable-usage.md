# 可接受的使用方式

ClawHub 託管供 OpenClaw 使用的 Skills、外掛、套件與市集詮釋資料。
請使用本頁判斷內容或發布行為是否適合放在 ClawHub 上。

這些規則適用於項目所執行的功能、要求使用者執行的內容、呈現自身的方式，以及發布者如何使用 ClawHub 的探索、安裝與信任機制。如需瞭解審核狀態與帳號信譽，請參閱[審核與帳號安全](/zh-TW/clawhub/moderation)。如需提出著作權或其他權利主張，請參閱[內容權利申請](/zh-TW/clawhub/content-rights)。

## 允許的內容

ClawHub 歡迎實用、易於理解且秉持善意發布的內容。

| 類別                                         | 符合以下條件時允許                                                                                                                      |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| 開發者生產力                           | 項目可協助使用者建置、測試、遷移、偵錯、記錄或維運軟體。                                               |
| UI、資料與自動化工作流程               | 範圍明確、清楚說明必要的認證資訊，且高風險操作包含審查、試執行、預覽或確認流程。 |
| 防禦性安全、審核與濫用審查 | 工具定位為用於經授權的審查、保留證據，並明確維持人工核准界線。                          |
| 個人或團隊工作流程                       | 工作流程使用經同意的帳號、透明的設定程序與明確的權限。                                            |
| 持續維護的目錄                              | 每個項目皆具獨特性與實用性、描述準確，並獲得合理維護。                                                |

情境很重要。同一主題在範圍有限的防禦性或經同意情境中可能可以接受，但若包裝成濫用工作流程，則不可接受。

## 禁止的市集行為

ClawHub 也會審查發布者使用市集的方式。請勿使用 ClawHub 操弄探索結果、指標、信任訊號、審核系統或使用者注意力。

禁止的市集行為包括：

- 大量發布大量粗製濫造、重複、僅供佔位或由機器產生，且看似不具實際使用者價值的項目
- 以近乎相同的 Skills 或外掛大量占據搜尋或類別頁面
- 發布數百個幾乎沒有使用量、維護、清楚來源或實質差異的項目
- 透過自動化、自行安裝迴圈、假帳號、協同行為、付費互動或其他非自然行為，人為灌高安裝次數、下載次數、星號或其他互動指標
- 建立或輪替帳號以規避審核、封鎖、發布者限制或市集審查
- 在所有權、來源、功能、安全狀態、安裝要求，或與其他專案或發布者的關係方面誤導使用者
- 未修正根本問題，卻反覆上傳已遭隱藏、移除或封鎖的內容

大量發布不一定就是濫用。若項目之間具有實質差異、描述準確、持續維護，且確實有真實使用者使用，則大型目錄可以接受。當大量發布伴隨內容空泛、重複、誤導、缺乏維護或人為推廣的項目時，大型目錄就會成為信任與安全問題。

## 內容權利

若你認為 ClawHub 上的內容侵害你的著作權或其他權利，請使用[內容權利申請](/zh-TW/clawhub/content-rights)。請勿使用一般市集檢舉功能提出著作權或權利主張，除非該項目同時不安全、具有惡意或具誤導性。

## 審查與處置

ClawHub 可能使用自動化檢查、濫用行為統計訊號、使用者檢舉與工作人員審查，識別不安全內容或濫用發布行為。單一訊號本身無法證明存在濫用行為；它可協助 ClawHub 判斷哪些內容需要審查。

我們可能會：

- 隱藏、暫緩、移除、軟刪除違規項目，或在資源類型支援時將其永久刪除
- 封鎖不安全版本的下載或安裝
- 撤銷 API 權杖
- 軟刪除相關內容
- 限制發布權限
- 封鎖屢次違規者或情節嚴重的違規者

對於明顯的濫用行為，我們不保證會先行警告再採取處置。如需瞭解檢舉、審核暫緩、隱藏項目、封鎖與帳號信譽，請參閱[審核與帳號安全](/zh-TW/clawhub/moderation)。
