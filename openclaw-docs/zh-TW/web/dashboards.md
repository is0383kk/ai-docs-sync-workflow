Control UI 中的每個討論串都有兩個面向：你熟悉的對話，以及
**儀表板**——由代理程式為你建立、包含即時小工具的網格。沒有
小工具的討論串就只是聊天。一旦釘選小工具，標頭中就會出現 **聊天 | 儀表板**
切換按鈕，儀表板會成為主要介面，而聊天則停駐在旁邊。

無須進行任何設定，也沒有需要另外設定的應用程式：儀表板是
核心功能，由討論串擁有、隨代理程式儲存，且不受
`/new` 和 `/reset` 影響（對話脈絡會清除，但面板會保留）。

## 透過提出要求建立儀表板

告訴代理程式你想看到什麼：

> 建立名為 revenue-graph 的小工具：顯示每月營收的互動式長條圖。
> 新增可切換檢視的 “Bars” 和 “Trend” 按鈕。將它釘選到我的
> 儀表板。

代理程式會先在聊天中內嵌呈現小工具，讓你在它移至其他位置前
先行查看。接下來：

- **由你釘選**：將游標停在內嵌小工具上，然後選擇 **釘選到儀表板**。
- **或由代理程式直接釘選**：只要提出要求，代理程式就會直接釘選，之後也能透過
  名稱更新——小工具具有固定名稱，因此「以 6 月的
  數據更新 revenue-graph」會就地取代內容，而面板維持原位。

小工具是獨立運作的小型應用程式（在嚴格沙箱中的 HTML/JS/SVG）。小工具內的按鈕
與檢視切換功能可立即使用——切換圖表檢視
完全不需要代理程式。

## 面板

- **流動式網格。** 透過控點拖曳小工具；所有內容都會自動重新排列並
  緊密排列。透過控點調整大小，或從小工具選單中選擇大小預設值（小、
  中、大、特大）。沒有人需要指定像素位置——
  你不需要，代理程式也不需要。
- **分頁。** 一個面板可以有多個頁面——例如概覽分頁，以及
  顯示單一大型小工具的聚焦分頁。每個分頁都會記住自己的聊天停駐
  位置。
- **停駐式聊天。** 在儀表板介面中，對話可停駐於
  左側、右側或底部，能像側邊欄一樣調整大小，也可以完全
  隱藏——再次顯示時，代理程式仍能接收你的訊息。
- **代理程式功能對等。** 你能執行的每項操作，代理程式也能使用其
  `dashboard` 工具執行：新增、更新、移動、調整大小及移除小工具，管理
  分頁、切換顯示中的分頁，以及移動或隱藏聊天停駐區。提出「將
  聊天放在左側並顯示財務分頁」，就能看到操作即時完成。

## 小工具允許執行的操作

只進行呈現的小工具不需要核准——它會立即顯示，就和
內嵌聊天小工具完全一樣，而且其網路存取功能會完全停用。

需要**連線能力**的小工具必須加以宣告，而你只需針對每個小工具
點按一次即可授予權限：

- **網路**（`net`）：直接從沙箱擷取已宣告的 HTTPS 來源——
  例如會自行從 API 重新整理的天氣卡片。
- **閘道資料**（`data`）：工作階段、用量或排程
  狀態等唯讀資料流，由閘道解析——小工具絕不會持有你的權杖。
- **自動化**（`actions`）：觸發特定排程工作，讓按鈕無須喚醒主要
  對話即可執行實際工作（可能會使用較小的模型）。
- **提示詞**（`prompt`）：將訊息傳送至你的討論串，不需要未核准小工具
  每次點擊時都必須進行的確認。

已啟用的外掛可將自己的具名唯讀資料流和動作新增至這些功能清單；停用外掛會移除這些整合。

授權會綁定至你所審查小工具的確切位元組內容與修訂版本。如果
代理程式變更小工具，並要求比你已核准範圍_更多_的權限，它就會回到
待處理狀態；在相同權限範圍內重新整理內容，則會保留授權。
代理程式應得知的小工具互動（你點選的篩選條件、你
切換的檢視）會以工作階段通知的方式低調傳達——它能持續掌握狀況，而不會
受到打斷。

## 面板上的 MCP 應用程式

如果你的閘道已設定 MCP 伺服器，聊天中出現的互動式 MCP 應用程式
可以像任何小工具一樣釘選。釘選的應用程式會在面板上
以新的工作階段重新啟動；預設只能顯示內容，而授予
小工具所宣告的伺服器工具後，即可完整互動——核准方式與其他項目相同，
只需點按一次，且綁定至修訂版本。

## 注意事項

- 重設具有面板的討論串時，系統會要求確認，並保留
  面板。
- 刪除討論串會一併刪除其面板。
- 面板存放於你的閘道上（位於所屬代理程式的資料庫中），並會出現在
  你連線的每部裝置上。
- 安全性模型、儲存細節與設計理由收錄於
  [儀表板架構](/zh-TW/web/dashboard-architecture)，其中包括
  已記錄的沙箱取捨。
