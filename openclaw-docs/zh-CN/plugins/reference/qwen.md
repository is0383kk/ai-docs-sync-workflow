# Qwen 插件

为 OpenClaw 添加对 Qwen、Qwen Cloud、Model Studio、DashScope、Qwen Token Plan、Bailian Token Plan 模型提供商的支持。

## 分发

- 软件包：`@openclaw/qwen-provider`
- 安装途径：npm；ClawHub：`clawhub:@openclaw/qwen-provider`

## 接口

提供商：`qwen`、`qwencloud`、`modelstudio`、`dashscope`、`qwen-token-plan`、`bailian-token-plan`；契约：`mediaUnderstandingProviders`、`videoGenerationProviders`
