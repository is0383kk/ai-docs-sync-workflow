# Workboard 插件

用于管理智能体所负责议题和会话的工作看板仪表盘。

## 分发

- 软件包：`@openclaw/workboard`
- 安装方式：随 OpenClaw 内置

## 接口

契约：`tools`；仪表盘数据绑定：`workboard.cards.list`、`workboard.stats`、`workboard.boards.list`；仪表盘操作动词：`workboard.dispatch`
