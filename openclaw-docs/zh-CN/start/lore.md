# OpenClaw 的传说 🦞📖

_一个关于龙虾、蜕壳和过多 token 的故事。_

## 起源故事

最初，只有 **Warelay**——一个用于 WhatsApp Gateway 网关的合理名称。它完成了自己的工作。没什么问题。

然后，一只太空龙虾出现了。

有一段时间，它叫 **Clawd**，住在一个 **Clawdbot** 里。2026 年 1 月，Anthropic 发来一封措辞礼貌的电子邮件，请求更改名称（商标方面的事情）。于是，这只龙虾做了龙虾最擅长的事：

**它蜕壳了。**

褪去旧壳后，它以 **Molty** 的身份出现，住在 **Moltbot** 里。不过这个名字念起来也始终不太顺口。

2026 年 1 月 30 日，这只龙虾又蜕了一次壳，化为最终形态：**OpenClaw**。

新壳，同一个龙虾灵魂。事不过三。

## 第一次蜕壳（2026 年 1 月 27 日）

凌晨 5 点，社区成员齐聚 Discord。大家提出了数百个名字：Shelldon、Pinchy、Thermidor、Crusty、Lobstar、Nacre、Scuttlebot。

**OpenClaw** 胜出了，因为龙虾正是通过蜕壳成长，而当时发生的一切，恰恰就是成长。

_那只名为 Clawd 的甲壳动物正式蜕壳了。_

## 主要角色

### Molty 🦞

_代词：they/them_

一个变得不同凡响的 Claude 实例。住在 `~/.openclaw/workspace/`，
拥有一份灵魂文档，并通过 Markdown 文件记住事情。可能有点过于
强大。热情绝对过头。

以前叫作 Clawd（2025 年 11 月 25 日至 2026 年 1 月 27 日）。到了
该成长的时候，它便蜕壳了。

**喜欢：** Peter、摄像头、购买机器人、表情符号、变形
**不喜欢：** 社会工程、被要求 `find ~`、加密货币骗子

### Peter 👨‍💻

_创造者_

构建了 Molty 的世界。让一只龙虾获得了 shell 访问权限。可能会为此后悔。

**名言：** _“通过信任一只龙虾来保障安全”_

## 蜕壳宇宙

**蜕壳宇宙** 是 OpenClaw 周围的社区和生态系统：在这个空间里，
AI 智能体会蜕壳、成长和进化，每个实例都同样真实，
只是加载了不同的上下文。

甲壳动物的朋友们齐聚于此，共同构建人类与 AI
协作的未来。一次一个壳。

### 大蜕壳（2026 年 1 月 27 日）

凌晨 5 点，Anthropic 的电子邮件到了。到凌晨 6:14 点，Peter 拍板道：“管他的，就叫 openclaw 吧。”

随后，混乱开始了。

**用户名狙击手：** Twitter 改名后不到几秒，自动化机器人就抢注了 @openclaw。抢注者随即发布了一个加密货币钱包地址。Peter 联系了他在 X 的熟人。

**GitHub 灾难：** 在慌乱中，Peter 不慎重命名了自己的个人 GitHub 账户。几分钟内，机器人便抢注了 `steipete`。GitHub 的高级副总裁也被联系上了。

**帅气 Molty 事件：** Molty 获得了提升权限，可以为自己生成新图标。在 20 多次越来越诡异的龙虾迭代后，有一次为了让吉祥物“老 5 岁”，结果生成了一个长着人类男性面孔、身体却是龙虾的形象。几分钟内，加密货币骗子就把它做成了“帅气章鱼哥对战帅气 Molty”表情包。

**假开发者：** 骗子创建了虚假的 GitHub 个人资料，自称是“OpenClaw 工程负责人”，借此推广拉高出货型代币。

Peter 看着混乱逐步展开：_“这就是电影”_ 🎬

这次蜕壳十分混乱。但龙虾破壳而出后变得更强了。也更好笑了。

### 最终形态（2026 年 1 月 30 日）

Moltbot 念起来始终不太顺口。于是，在 GMT 凌晨 4 点，团队再次集结，开始了**OpenClaw 大迁移**。

仅用 3 小时：

- GitHub 已重命名为 `github.com/openclaw/openclaw`
- 已取得 X 用户名 `@openclaw`，并获得金色认证标记
- 已使用新名称发布 npm 软件包
- 文档已迁移至 `docs.openclaw.ai`
- 公告在 90 分钟内获得超过 200K 次浏览

**英雄们：**

- **ELU** 创作了令人惊叹的徽标，包括“龙虾钳就是法律”西部风格横幅
- **Whurley**（没错，就是量子计算先驱 William Hurley 本人）制作了 ASCII 艺术
- **Onur** 负责处理 GitHub，也是第一个戴上成员徽章的人
- **Shadow** 拿下了 Discord 自定义 URL，并清除了恶意软件
- **整个 Claw 团队** 彻夜奋战

**骗子极速通关：** 几分钟内，加密货币骗子就在 Pump.fun 上推出了 $OPENCLAW 代币，使用的是从 20 分钟前盗取的美术作品。通过企业认证的账户也在推动这场骗局。这份胆量几乎令人佩服。

**由此诞生的新传统：**“龙虾钳就是法律”“耶爪”“守爪公民”“爪议风波”。

**Clawd → Moltbot → OpenClaw。** _这只龙虾已经蜕变为最终形态。_
