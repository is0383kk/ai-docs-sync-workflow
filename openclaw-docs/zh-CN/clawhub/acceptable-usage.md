# 可接受使用规范

ClawHub 托管 OpenClaw 的 Skills、插件、软件包和市场元数据。
使用本页面判断内容或发布行为是否适合在 ClawHub 上进行。

这些规则适用于条目所执行的操作、要求用户运行的内容、呈现自身的方式，以及发布者使用 ClawHub 的设备发现、安装和信任机制的方式。有关审核状态和账户状态，请参阅
[审核与账户安全](/clawhub/moderation)。有关版权或其他权利主张，请参阅
[内容权利请求](/clawhub/content-rights)。

## 允许的内容

ClawHub 欢迎有用、易于理解且出于善意发布的内容。

| 类别                                             | 允许条件                                                                                                                         |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 开发者生产力                                     | 条目可帮助用户构建、测试、迁移、调试、记录或运维软件。                                                                           |
| UI、数据和自动化工作流                           | 范围明确，清楚说明所需凭据，且高风险操作包含审查、试运行、预览或确认流程。                                                       |
| 防御性安全、审核和滥用行为审查                   | 工具定位为用于经授权的审查，能够保留证据，并明确划定人工审批边界。                                                               |
| 个人或团队工作流                                 | 工作流使用基于同意授权的账户、透明的设置流程和明确的权限。                                                                       |
| 持续维护的目录                                   | 每个条目各不相同、实用、描述准确且得到合理维护。                                                                                 |

具体情境很重要。同一主题在范围有限的防御性或基于同意授权的场景中可能可以接受，但如果被包装为滥用工作流，则不可接受。

## 禁止的内容

ClawHub 不托管以滥用、欺骗、不安全执行或侵犯权利为主要目的的内容。

| 类别                                                        | 禁止内容                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| 平台滥用和规避封禁                                          | 被封禁后创建隐蔽账户、养号或批量培育账户、虚假互动、多账户自动化、批量发帖、垃圾信息机器人，或为逃避检测而构建的自动化。                                                                                                                                                                                                          |
| 欺诈、诈骗和欺骗性金融工作流                                | 伪造证书或发票、欺骗性付款流程、诈骗推广、虚假社会认同、用于欺诈的合成身份工作流，或在没有明确人工审批的情况下使用支出或收费工具。                                                                                                                                                                                                |
| 侵犯隐私的信息扩充或监控                                    | 为发送垃圾信息抓取联系人、公开他人隐私信息、跟踪骚扰、提取潜在客户并进行未经请求的推广、秘密监控、未经同意的生物特征匹配，或使用泄露的数据或数据泄露转储。                                                                                                                                                                          |
| 未经同意的冒充或身份操纵                                    | 换脸、数字孪生、克隆网红、虚假人设，或用于冒充或误导他人的其他工具。                                                                                                                                                                                                                                                            |

## 禁止的市场行为

ClawHub 还会审查发布者使用市场的方式。请勿使用 ClawHub 操纵设备发现、指标、信任信号、审核系统或用户注意力。

禁止的市场行为包括：

- 批量发布大量低投入、重复、占位或机器生成的条目，且这些条目似乎没有真正的用户价值
- 用几乎相同的 Skills 或插件充斥搜索或分类页面
- 发布数百个几乎或完全没有使用量、维护、来源说明或实质性差异的条目
- 通过自动化、自我安装循环、虚假账户、协同行为、付费互动或其他非自然行为，人为夸大安装量、下载量、星标数或其他互动指标
- 创建或轮换账户，以规避审核、封禁、发布者限制或市场审查
- 在所有权、来源、能力、安全状况、安装要求，或与其他项目或发布者的关联关系方面误导用户
- 在未解决根本问题的情况下，反复上传已被隐藏、移除或屏蔽的内容

高频发布并不一定构成滥用。如果条目之间存在实质差异、描述准确、得到维护且有真实用户使用，则大型目录是可以接受的。当大量条目内容单薄、重复、具有误导性、缺乏维护或经过人为推广时，大型目录就会成为信任与安全问题。

## 内容权利

如果你认为 ClawHub 上的内容侵犯了你的版权或其他权利，请使用
[内容权利请求](/clawhub/content-rights)。请勿使用普通市场举报来提出版权或权利主张，除非该条目还存在不安全、恶意或误导性问题。

## 审查与执行

ClawHub 可能使用自动检查、滥用行为统计信号、用户举报和工作人员审查，来识别不安全内容或滥用发布行为。单个信号本身不能证明存在滥用；它可以帮助 ClawHub 判断哪些内容需要审查。

我们可能会：

- 隐藏、暂扣、移除、软删除违规条目，或在相应资源类型支持的情况下彻底删除违规条目
- 阻止下载或安装不安全的版本
- 撤销 API 令牌
- 软删除关联内容
- 限制发布权限
- 封禁屡次违规或严重违规者

对于明显的滥用行为，我们不保证先警告再采取措施。有关举报、审核暂扣、隐藏条目、封禁和账户状态的信息，请参阅
[审核与账户安全](/clawhub/moderation)。
