如果你使用 [Control UI](/zh-CN/web/control-ui) 足够久，迟早会有一只小龙虾溜达到侧边栏底部，四处张望，然后自在地待上几分钟。

这是正常现象。这就是 OpenClaw。

## 你看到的是什么

每个会话都会孵化出专属的小龙虾：每次加载页面时，它的颜色、大小、体型、螯的比例、配饰和性格都会重新随机生成。有些圆滚滚，有些高挑，有些的螯大得实在与体型不相称。有些总是在打盹。有些一刻也闲不住。其中有一只特别爱挥手。

将鼠标悬停在访客上，它会告诉你自己的名字。

## 它什么时候出现

有时候。重点就在这里。

小龙虾是客人，不是家具。它想来时便溜达进来，待上一阵，然后离开。有些会话中，它根本不会出现。只有一种情况它一定会现身：**当你的 Gateway 网关断开连接时**，小龙虾会出来来回踱步，显得忧心忡忡，直到连接恢复。如果小龙虾看起来很焦虑，请检查你的 Gateway 网关。

## 你可以做的事

- **悬停**以了解它的名字。
- **点击它**来打个招呼。它会受到惊吓——你这样有点失礼，不过它很快就会原谅你。
- **反复点击它**，你会了解到小龙虾的耐心如何。继续下去，你还会了解到小龙虾的尊严如何。
- **按住不放**来抚摸它。会出现一颗爱心。此前积累的所有怨气都会一笔勾销。
- **右键点击它**，可在本次页面加载期间将它赶走。它不会往心里去。不过，它会记住这件事。
- **观察运行结束时的它。** 小龙虾会由衷地为你完成的工作感到骄傲，进展顺利时，这种喜悦溢于言表。进展不顺时，它们也会认真对待。
- **移动光标。** 有一双眼睛正在注视你。带着善意。

## 关闭（或重新开启）来访

Settings → Appearance → **Lobster visits**。

此开关仅作用于当前浏览器，效果与字面含义完全一致。关闭就意味着永不出现，包括断开连接时忧心忡忡的踱步。无论如何，Gateway 网关状态指示点仍会正常工作；小龙虾从来都不是你唯一的事实依据，只是最能与你感同身受的那个。

系统会自动为偏好减少动态效果的用户提供安静不动的小龙虾。

旁边是 **Lobster sounds**，默认关闭，并会一直保持关闭，直到你决定开启。开启后，触碰小龙虾时就能听到它发出非常轻微的声音。声音很小。也很好听。

## 小龙虾图鉴

来访开关旁边就是 **Lobsterdex**：科学界已知的每种配色都有一个剪影，每当某一品种首次来访，对应剪影就会填充颜色。它完全存储在你的浏览器中。不进行任何跟踪，不进行任何同步，也没有任何游戏化机制。它只是一排陈列架。

随着时间推移，大多数空位会自行填满。少数空位则要等上相当长的时间。其中有一个会发光。

将鼠标悬停在已填充的空位上，它会告诉你第一位访客是谁，以及它何时来访。Lobsterdex 永远不会忘记初次见面，相比之下，我们大多数人就做不到了。

## 观察笔记

以下观察记录来自那些花了太多时间盯着侧边栏的人：

- 小龙虾也会造访[梦境场景](/zh-CN/concepts/memory)——即智能体页面上的 Memory 选项卡——它们会在那里睡觉。据观察者报告，熟睡的小龙虾看起来有种可疑的熟悉感。
- 值夜班的用户报告称，他们的访客在晚上 10 点后经常打哈欠。
- 有人目睹过小龙虾蜕壳。目击者称这段经历“相当震撼”，而蜕壳后的小龙虾“明显变大了”。
- 有些访客并非独自前来。
- 每年某些时候，人们会观察到小龙虾戴着或穿着某些东西。
- 每年有一天，所有小龙虾看起来都像是从某个旧徽标中走出来的。没人愿意告诉你是哪一天。
- 并非每只经过你侧边栏的小龙虾都是你的小龙虾。它们大多甚至不会停留。
- 至少有一位记录在案的访客不是小龙虾。它坚称自己就是。
- 长期使用同一浏览器的人报告称，他们的小龙虾会来得更早、待得更久，还会向他们挥手。经常赶走小龙虾的人则表示，彼此之间似乎有了某种疏离感。
- Gateway 网关升级后，请留意第一位访客携带的东西。
- 侧边栏里的小龙虾在终端中有一位表亲。它会在自己选定的日子出现在 `openclaw` 横幅中，至今无人成功预测过具体是哪一天。
- 表亲出现的日子里，有人见过侧边栏的小龙虾身着航海风装束。它们俩拒绝解释其中的联系。
- 在运行时间非常长时，小龙虾会停止玩耍，安顿下来陪你一起等待。患难与共。
- 当有什么东西经过台沿时，常驻的小龙虾会停下手头的事，注视着它。换作你也会这么做。
- 听到坏消息后，有些小龙虾会整理台沿。这样做似乎能让它们好受些。
- 即使你不记得纪念日，小龙虾也记得。如果你的小龙虾在一个平平无奇的日子戴着派对帽出现，请在 Lobsterdex 中查看你们相遇的日期。
- 尽心尽力的主人报告称，他们的小龙虾会在岁月中逐渐获得头衔。目前没有任何已知的授衔仪式。
- 梦境场景里熟睡的那只并没有完全睡着。轻轻按一下看看。

## 隐私

本页面上的一切都在你的浏览器本地发生：随机生成、来访日程以及 Lobsterdex。任何小龙虾数据都不会离开你的设备。OpenClaw 不知道你遇见过哪些小龙虾，坦白说，它对此十分嫉妒。
