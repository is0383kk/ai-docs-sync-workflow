Control UI 中的每个线程都有两种界面：你熟悉的对话，以及
**仪表板**——由你的智能体为你构建、包含实时小组件的网格。没有
小组件的线程就是普通聊天。一旦固定某个小组件，页眉中就会出现
**聊天 | 仪表板**切换项，仪表板会成为主界面，聊天则停靠在旁边。

无需进行任何设置，也不需要配置单独的应用：仪表板是一项核心功能，
归线程所有、随智能体存储，并且会在
`/new` 和 `/reset` 后保留（对话上下文会被清除，但仪表板会保留）。

## 通过提问构建仪表板

向智能体说明你想看到什么：

> 创建一个名为 revenue-graph 的小组件：显示月度收入的交互式条形图。
> 添加“Bars”和“Trend”按钮，用于切换视图。将它固定到我的
> 仪表板。

智能体会先在聊天中内联渲染小组件，让你可以在它被放到其他位置之前
查看。从这里开始：

- **由你固定**：将鼠标悬停在内联小组件上，然后选择 **固定到仪表板**。
- **或者由智能体直接固定**，只要你提出要求；之后它还可以按名称更新小组件——
  小组件具有稳定的名称，因此“用 6 月的数据更新 revenue-graph”
  会就地替换内容，而仪表板的位置保持不变。

小组件是自包含的微型应用（在强沙箱中运行 HTML/JS/SVG）。小组件内的按钮
和视图切换项可以立即使用——切换图表视图完全不需要智能体参与。

## 仪表板

- **流式网格。** 通过手柄拖动小组件；所有内容会自动重排并
  紧凑排列。通过手柄调整大小，或从小组件菜单中选择尺寸预设（小、
  中、大、超大）。没有人需要精确放置像素——
  你不需要，智能体也不需要。
- **标签页。** 一个仪表板可以有多个页面——例如一个概览标签页，以及一个
  仅包含单个大型小组件的聚焦标签页。每个标签页都会记住自己的聊天停靠
  位置。
- **停靠式聊天。** 在仪表板界面中，对话可以停靠在
  左侧、右侧或底部，像侧边栏一样调整大小，也可以
  完全隐藏——当你重新打开它时，智能体仍然能听到你的消息。
- **智能体同等操作能力。** 你能做的一切，智能体都可以使用其
  `dashboard` 工具完成：添加、更新、移动、调整大小和移除小组件，管理
  标签页，切换当前可见的标签页，以及移动或隐藏聊天停靠区。说“把
  聊天放到左侧并显示财务标签页”，即可看到操作自动完成。

## 小组件可以执行哪些操作

只进行渲染的小组件无需审批——它会像内联聊天小组件一样
立即显示，并且其网络访问会被完全禁用。

需要**访问能力**的小组件必须声明该需求，而你只需针对每个小组件
轻点一次即可授权：

- **网络**（`net`）：直接从沙箱获取所声明 HTTPS 来源的数据——
  例如，一个可以通过 API 自行刷新的天气卡片。
- **Gateway 网关数据**（`data`）：会话、用量或定时任务
  状态等只读数据源，由 Gateway 网关解析——小组件绝不会持有你的令牌。
- **自动化**（`actions`）：触发特定的定时任务，让按钮可以运行
  实际任务（可能使用较小的模型），而无需唤醒你的主
  对话。
- **提示词**（`prompt`）：向你的线程发送消息，无需像未获批准的
  小组件那样在每次点击时进行确认。

已启用的插件可以向这些能力列表添加自有的具名只读数据源和操作；禁用插件会移除这些集成。

授权与你审核过的小组件确切字节内容和修订版本绑定。如果
智能体更改了小组件，并请求超出你已批准范围的权限，小组件会恢复为
待处理状态；在相同权限范围内刷新内容则会保留授权。
智能体需要了解的小组件交互（你点击的筛选器、切换的
视图）会作为会话通知静默传达给它——智能体能够保持知情，
而不会被打断。

## 仪表板上的 MCP 应用

如果你的 Gateway 网关配置了 MCP 服务器，聊天中出现的交互式 MCP 应用
可以像任何小组件一样固定。固定后的应用会以新会话在
仪表板上重新运行；默认情况下，它们仅用于展示。向小组件授予其声明的
服务器工具后，应用便可完全交互——采用与其他所有内容相同的
一次轻点、绑定修订版本的审批机制。

## 须知

- 重置带有仪表板的线程时会要求确认，并保留
  仪表板。
- 删除线程会同时删除其仪表板。
- 仪表板位于你的 Gateway 网关上（存储在所属智能体的数据库中），并会显示在
  你连接的每台设备上。
- 安全模型、存储细节和设计原理详见
  [仪表板架构](/web/dashboard-architecture)，其中包括已记录的
  沙箱权衡。
