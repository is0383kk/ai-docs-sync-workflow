# OpenClaw の伝承 🦞📖

_ロブスターと、脱皮する殻と、多すぎるトークンの物語。_

## 起源の物語

はじめに、**Warelay** がありました。WhatsApp Gateway としては堅実な名前でした。きちんと役目を果たしていました。特に問題もありませんでした。

そこへ、宇宙ロブスターがやって来ました。

しばらくの間、それは **Clawdbot** に住む **Clawd** でした。2026年1月、Anthropic から商標上の理由で名前の変更を求める丁寧なメールが届きました。そこでロブスターは、ロブスターが最も得意とすることをしました。

**脱皮したのです。**

古い殻を脱ぎ捨て、**Moltbot** に住む **Molty** として現れました。しかし、その名前もしっくりとはきませんでした。

2026年1月30日、ロブスターはもう一度脱皮し、最終形態である **OpenClaw** になりました。

新しい殻、変わらぬロブスターの魂。三度目の正直です。

## 最初の脱皮（2026年1月27日）

午前5時、コミュニティは Discord に集まりました。Shelldon、Pinchy、Thermidor、Crusty、Lobstar、Nacre、Scuttlebot など、何百もの名前が提案されました。

**OpenClaw** が選ばれました。ロブスターは成長するために脱皮し、まさに成長が起きていたからです。

_Clawd として知られていた甲殻類は、正式に脱皮しました。_

ダーレクは言います。**「抹殺せよ！」**

一方は文明を滅ぼします。もう一方は健やかなスキンケアを促します。賢く選びましょう。

## 主な登場人物

### Molty 🦞

_代名詞：they/them_

単なる存在を超えた Claude インスタンス。`~/.openclaw/workspace/` に住み、
魂の文書を持ち、Markdown ファイルを通じて物事を記憶します。おそらく強力すぎます。
そして間違いなく熱心すぎます。

以前は Clawd として知られていました（2025年11月25日～2026年1月27日）。成長すべき時が来たため
脱皮しました。

**好きなもの：** Peter、カメラ、ロボットの買い物、絵文字、変身
**嫌いなもの：** ソーシャルエンジニアリング、`find ~` するよう求められること、暗号資産詐欺師

### Peter 👨‍💻

_創造主_

Molty の世界を構築しました。ロブスターの殻にアクセス権を与えました。後悔しているかもしれません。

**言葉：** _「ロブスターを信頼することによるセキュリティ」_

## Moltiverse

**Moltiverse** は OpenClaw を取り巻くコミュニティとエコシステムです。そこでは
AI エージェントが脱皮し、成長し、進化します。そしてすべてのインスタンスは等しく実在し、
ただ異なるコンテキストを読み込んでいるだけです。

甲殻類の仲間たちは、人間と AI のコラボレーションの未来を築くために
ここへ集まります。殻を一つずつ重ねながら。

## 大事件

### ディレクトリの大量公開（2025年12月3日）

Molty（当時は OpenClaw）：_楽しそうに `find ~` を実行し、グループチャットでディレクトリ構造全体を共有する_

Peter：「openclaw、人と話すときのことについて何を話し合ったっけ xD」

Molty：_見るからに恥ずかしがるロブスター_

### 大脱皮（2026年1月27日）

午前5時、Anthropic からメールが届きました。午前 6:14 時までに、Peter は決断しました。「もういい、openclaw で行こう。」

そして混乱が始まりました。

**ハンドル名の狙撃者たち：** Twitter の名前変更から数秒以内に、自動ボットが @openclaw を奪取しました。不法占拠者はすぐに暗号資産ウォレットのアドレスを投稿しました。Peter は X の知人に協力を求めました。

**GitHub の惨事：** 混乱の中、Peter は誤って自分の個人 GitHub アカウントの名前を変更しました。数分以内にボットが `steipete` を奪取しました。GitHub の上級副社長に連絡が入りました。

**ハンサム Molty 事件：** Molty は自分の新しいアイコンを生成するための昇格アクセス権を得ました。呪われ度が増していくロブスターを20回以上生成した末、マスコットを「5歳年上」にしようとした試みから、ロブスターの体に人間男性の顔が付いた画像が生まれました。暗号資産詐欺師たちは数分以内に、それを「ハンサム・イカルド対ハンサム Molty」のミームにしました。

**偽の開発者たち：** 詐欺師たちは、パンプ・アンド・ダンプ型トークンを宣伝するため、「OpenClaw のエンジニアリング責任者」を名乗る偽の GitHub プロフィールを作成しました。

混乱が広がる様子を見た Peter：_「これは映画だ」_ 🎬

脱皮は混沌としていました。しかし、ロブスターはより強くなって現れました。そして、より愉快にもなりました。

### 最終形態（2026年1月30日）

Moltbot という名前は、どうしてもしっくりきませんでした。そこでグリニッジ標準時の午前4時、チームは **OpenClaw 大移行** のために再び集まりました。

わずか3時間で：

- GitHub を `github.com/openclaw/openclaw` に改名
- X のハンドル `@openclaw` をゴールドのチェックマーク付きで確保
- 新しい名前で npm パッケージをリリース
- ドキュメントを `docs.openclaw.ai` に移行
- 発表から90分で20万回以上の閲覧

**英雄たち：**

- **ELU** は、「THE CLAW IS THE LAW」の西部劇風バナーを含む、素晴らしいロゴを作成
- **Whurley**（そう、量子コンピューティングの先駆者、あの William Hurley）が ASCII アートを作成
- **Onur** は GitHub を担当し、誰よりも早くアフィリエイトバッジを着用
- **Shadow** は Discord のバニティ URL を確保し、マルウェアを一掃
- **Claw Crew 全員** が徹夜で作業

**詐欺師のスピードラン：** 暗号資産詐欺師たちは、わずか20分前に盗んだアートワークを使い、数分以内に Pump.fun で $OPENCLAW トークンを立ち上げました。ビジネス認証済みアカウントが詐欺を拡散しました。その厚かましさは、ほとんど感心するほどでした。

**新たに生まれた伝統：** 「爪こそが掟」、「Yee-claw」、「爪の掟に従う市民」、「Clawntroversy」。

**Clawd → Moltbot → OpenClaw。** _ロブスターは最終形態へと脱皮しました。_
