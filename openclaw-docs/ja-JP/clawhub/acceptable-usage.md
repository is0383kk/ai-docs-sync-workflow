# 利用上の許容範囲

ClawHub は、OpenClaw 向けのスキル、プラグイン、パッケージ、およびマーケットプレイスのメタデータをホストします。
コンテンツや公開時の行為が ClawHub に適しているかどうかを判断する際は、
このページを参照してください。

これらのルールは、掲載項目の機能、ユーザーに実行を求める内容、自身の表現方法、および公開者による ClawHub の検索、インストール、信頼性に関する機能の利用方法に適用されます。モデレーション状態とアカウントの健全性については、
[モデレーションとアカウントの安全性](/clawhub/moderation)を参照してください。著作権またはその他の権利に関する申し立てについては、
[コンテンツの権利に関する申請](/clawhub/content-rights)を参照してください。

## 許可されるコンテンツ

ClawHub は、有用で分かりやすく、誠実に公開されたコンテンツを歓迎します。

| カテゴリ                                         | 許可される条件                                                                                                                      |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| 開発者の生産性向上                           | 掲載項目が、ソフトウェアの構築、テスト、移行、デバッグ、文書化、または運用に役立つこと。                                               |
| UI、データ、自動化のワークフロー               | 適用範囲が明確で、必要な認証情報が明示され、リスクのある操作にレビュー、ドライラン、プレビュー、または確認の手順が含まれていること。 |
| 防御的セキュリティ、モデレーション、不正利用のレビュー | ツールが許可されたレビューを目的として位置付けられ、証拠を保持し、人間による承認の境界が明確に保たれていること。                          |
| 個人またはチームのワークフロー                       | ワークフローで、同意に基づくアカウント、透明性のあるセットアップ、および明示的な権限が使用されていること。                                            |
| 保守されているカタログ                              | 各掲載項目が個別性と有用性を備え、正確に説明され、適切に保守されていること。                                                |

文脈が重要です。同じテーマでも、限定的な防御目的や
同意に基づく環境では許容される一方、不正利用のワークフローとしてパッケージ化されている場合は許容されません。

## 禁止されるマーケットプレイス上の行為

ClawHub は、公開者によるマーケットプレイスの利用方法も審査します。検索結果、指標、信頼性を示す情報、モデレーションシステム、またはユーザーの注意を
操作する目的で ClawHub を使用しないでください。

禁止されるマーケットプレイス上の行為には、以下が含まれます。

- 実際のユーザー価値があるように見えない、低品質、重複、プレースホルダー、または
  機械生成の掲載項目を大量に一括公開すること
- ほぼ同一のスキルまたはプラグインで検索画面やカテゴリ画面を埋め尽くすこと
- 利用実績、保守、ソースの明確性、または有意な差別化がほとんど、あるいはまったくない
  掲載項目を数百件公開すること
- 自動化、自己インストールのループ、偽アカウント、組織的な
  活動、有料エンゲージメント、またはその他の非オーガニックな行為により、インストール数、ダウンロード数、スター数、その他のエンゲージメント
  指標を人為的に水増しすること
- モデレーション、利用禁止、公開者の制限、または
  マーケットプレイスの審査を回避するために、アカウントを作成または切り替えること
- 所有権、ソース、機能、セキュリティ体制、
  インストール要件、または他のプロジェクトや公開者との関係についてユーザーを誤解させること
- 根本的な問題を修正せずに、すでに非表示、削除、またはブロックされた
  コンテンツを繰り返しアップロードすること

大量公開が自動的に不正利用となるわけではありません。掲載項目に有意な違いがあり、正確に説明され、保守され、
実際のユーザーに利用されている場合、大規模なカタログも許容されます。内容が乏しい、重複している、誤解を招く、保守されていない、または
人為的に宣伝されている掲載項目と大量公開が組み合わさると、大規模なカタログは信頼性と安全性の問題になります。

## コンテンツの権利

ClawHub 上のコンテンツが自身の著作権またはその他の権利を侵害していると思われる場合は、
[コンテンツの権利に関する申請](/clawhub/content-rights)を利用してください。その掲載項目が安全でない、
悪意がある、または誤解を招くものでもある場合を除き、通常のマーケットプレイス報告を著作権または権利に関する申し立てに使用しないでください。

## 審査と措置

ClawHub は、安全でないコンテンツや不正な公開行為を特定するために、自動チェック、統計的な不正利用シグナル、ユーザー報告、および
スタッフによる審査を使用する場合があります。シグナル自体が不正利用を証明するわけではなく、ClawHub が審査の必要な対象を判断するために役立ちます。

以下の措置を講じる場合があります。

- 違反する掲載項目を非表示、保留、削除、論理削除し、リソース種別が対応している場合は、
  物理削除する
- 安全でないリリースのダウンロードまたはインストールをブロックする
- API トークンを失効させる
- 関連コンテンツを論理削除する
- 公開権限を制限する
- 違反を繰り返す者または重大な違反者を利用禁止にする

明らかな不正利用に対して、必ず事前に警告してから措置を講じることは保証しません。報告、モデレーションによる保留、
非表示の掲載項目、利用禁止、およびアカウントの健全性については、[モデレーションとアカウントの安全性](/clawhub/moderation)を参照してください。
