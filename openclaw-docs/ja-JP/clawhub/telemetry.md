# テレメトリ

ClawHub は、Skills と Plugin のインストール数の集計に必要な最小限の CLI テレメトリを使用します。

## テレメトリが収集される場合

テレメトリが送信されるのは、以下の場合のみです。

- CLI にログインしている。
- `clawhub install <slug>` を実行するか、認証済みの
  `openclaw plugins install clawhub:<package>` のインストールを完了する。
- テレメトリが**無効になっていない**（下記の「無効にする方法」を参照）。

ログインしていない場合、何も報告されません。

## 収集する情報

Skills または Plugin がインストールされ、ローカルのインストール記録が永続化された後、CLI はベストエフォートでインストールイベントを 1 件送信します。

イベントには以下が含まれます。

- インストールされた Skills のスラッグまたは Plugin の正規パッケージ名。
- `version`: 判明している場合は、インストールされたバージョン。

### 収集_しない_情報

- フォルダーパスやフォルダーから派生した識別子。
- ファイルの内容。
- 実行ごとのログ、プロンプト、その他の CLI 出力。

## インストール数

Skills について、ClawHub は以下を管理します。

- `installsAllTime`: その Skills について少なくとも 1 回の CLI インストールを報告したユニークユーザー数。
- `installsCurrent`: インストールを報告し、テレメトリを削除していない
  ユニークユーザー数。

Plugin について、ClawHub は各ユーザーおよびパッケージから報告された最初のインストール成功をカウントします。
インストールの繰り返しや更新では、インストール総数を増やさずに記録済みのバージョンを更新します。

## 透明性とユーザーによる制御

すべてのユーザーに表示されるのは、**集計されたインストールカウンター**のみです。

アカウントを削除すると、テレメトリデータも削除され、インストールカウンターへの寄与も除外されます。

## テレメトリを無効にする方法

環境変数を設定します。

```bash
export CLAWHUB_DISABLE_TELEMETRY=1
```

この変数を設定すると、CLI はインストールテレメトリを送信しません。
