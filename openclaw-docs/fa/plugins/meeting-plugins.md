OpenClaw برای Google Meet، جلسه‌های Microsoft Teams و Zoom، Pluginهای جداگانه‌ای دارد. هر سه می‌توانند از طریق Chrome به جلسه بپیوندند، از حالت‌های مشارکت یکسان استفاده کنند و Chrome را یا روی میزبان Gateway یا روی یک Node جفت‌شده اجرا کنند. URLهای پلتفرم، مدل نصب و قابلیت‌های افزوده آن‌ها متفاوت است.

این Pluginها در جلسه‌ها مشارکت می‌کنند. آن‌ها از کانال‌های پیام‌رسانی مانند [کانال Microsoft Teams](/fa/channels/msteams) و [Plugin تماس صوتی](/fa/plugins/voice-call) جدا هستند.

## انتخاب Plugin

| پلتفرم        | Plugin                                      | پیوندهای جلسه پذیرفته‌شده                                                                                      | نصب                                    | مسیرهای مشارکت                                      | قابلیت‌های مختص پلتفرم                                                                                |
| --------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Google Meet     | [`google-meet`](/fa/plugins/google-meet)       | `meet.google.com/...`                                                                                       | نصب از npm یا ClawHub؛ به‌طور پیش‌فرض فعال است | Chrome محلی، Chrome روی یک Node جفت‌شده یا شماره‌گیری ورودی Twilio | می‌تواند از طریق API ‏Meet یا مرورگر واردشده به حساب، جلسه ایجاد کند؛ می‌تواند با OAuth مصنوعات پشتیبانی‌شده Meet را بخواند |
| Microsoft Teams | [`teams-meetings`](/plugins/teams-meetings) | پیوندهای کاری زیر `teams.microsoft.com/l/meetup-join/...` و پیوندهای مصرف‌کننده زیر `teams.live.com/meet/...` | گنجانده شده؛ به‌طور پیش‌فرض فعال است                    | Chrome محلی یا Chrome روی یک Node جفت‌شده                  | پیوستن به‌عنوان مهمان برای جلسه‌های کاری و مصرف‌کننده                                                                     |
| Zoom            | [`zoom-meetings`](/plugins/zoom-meetings)   | `zoom.us/j/...` و زیردامنه‌های حساب مانند `example.zoom.us/j/...`                                      | گنجانده شده؛ به‌طور پیش‌فرض فعال است                    | Chrome محلی یا Chrome روی یک Node جفت‌شده                  | پیوستن به‌عنوان مهمان از طریق Zoom Web App                                                                           |

وقتی به ایجاد جلسه، مصنوعات API گوگل یا مسیر تلفنی Twilio نیاز دارید، Google Meet را انتخاب کنید. برای مشارکت مستقیم مهمان از طریق مرورگر در آن پلتفرم‌ها، Teams یا Zoom را انتخاب کنید. Pluginهای Teams و Zoom جلسه ایجاد نمی‌کنند، شماره‌گیری ورودی انجام نمی‌دهند، API ارائه‌دهنده را فراخوانی نمی‌کنند و صدای یا ویدیوی جلسه را ضبط نمی‌کنند.

## انتخاب حالت

سه Plugin حالت‌های یکسانی دارند:

| حالت         | رفتار                                                                                              | الزامات صوتی                                      |
| ------------ | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| `agent`      | رونویسی بلادرنگ به عامل پیکربندی‌شده OpenClaw می‌رود؛ TTS معمول OpenClaw پاسخ را می‌خواند.  | پاسخ صوتی Chrome به پل BlackHole و SoX نیاز دارد. |
| `bidi`       | یک مدل صوتی بلادرنگ مستقیماً گوش می‌دهد و پاسخ می‌دهد.                                                  | پاسخ صوتی Chrome به پل BlackHole و SoX نیاز دارد. |
| `transcribe` | فقط برای مشاهده به جلسه می‌پیوندد و هنگامی که پلتفرم زیرنویس ارائه کند، رونوشتی محدود از زیرنویس زنده در دسترس قرار می‌دهد. | بدون پل پاسخ صوتی BlackHole یا SoX.                   |

وقتی عامل فقط به متن جلسه نیاز دارد، از `transcribe` استفاده کنید. برای استدلال و ابزارهای عادی OpenClaw، از `agent` استفاده کنید. وقتی صدای مستقیم با تأخیر کم مهم‌تر از هدایت هر نوبت از طریق عامل معمولی است، از `bidi` استفاده کنید.

رونوشت زنده محدود فقط در حالت `transcribe` در دسترس می‌ماند. در هر
سه حالت، پیوستن از طریق مرورگر همچنین ردیف‌های تکمیل‌شده زیرنویس و یک
خلاصه استخراج‌شده را در پایگاه داده وضعیت مشترک ماندگار می‌کند. ترک جلسه،
زیرنویس‌های قابل‌مشاهده را نهایی می‌کند و خلاصه را می‌نویسد؛ برای فهرست‌کردن،
بررسی یا برون‌بری آن از [`openclaw transcripts`](/fa/cli/transcripts)
استفاده کنید. این مسیر یادداشت‌های ماندگار، رونوشت زنده مشورت با عامل را تغییر
نمی‌دهد و ضبط صوتی یا ویدیویی ایجاد نمی‌کند.

یادداشت‌های خودکار به‌طور پیش‌فرض فعال‌اند. برای غیرفعال‌کردن
یادداشت‌های ماندگار در سراسر سیستم، `transcripts.enabled: false` را تنظیم کنید. جلسه‌ای که صراحتاً با `transcribe` انتخاب شده باشد،
دنباله محدود زیرنویس زنده خود را بدون نوشتن ردیف‌های ماندگار حفظ می‌کند. در دسترس‌بودن
زیرنویس همچنان به پلتفرم جلسه، حساب، زبان و خط‌مشی میزبان بستگی دارد.

## آماده‌سازی Chrome و صدا

Chrome می‌تواند روی میزبان Gateway یا یک Node جفت‌شده اجرا شود. Node راه‌دور Chrome باید `browser.proxy` به‌همراه فرمان پلتفرم را مجاز کند:

| Plugin          | فرمان Node           |
| --------------- | ---------------------- |
| Google Meet     | `googlemeet.chrome`    |
| Microsoft Teams | `teamsmeetings.chrome` |
| Zoom            | `zoommeetings.chrome`  |

برای حالت `agent` یا `bidi` از طریق Chrome، ‏Chrome را روی macOS اجرا کنید و وابستگی‌های صوتی مشترک را روی همان میزبان نصب کنید:

```bash
brew install blackhole-2ch sox
sudo reboot
system_profiler SPAudioDataType | grep -i BlackHole
command -v sox
```

وقتی Chrome روی یک Node جفت‌شده اجرا می‌شود، میزبان Gateway همچنان مالک عامل OpenClaw و اطلاعات اعتباری مدل است. برای حالت `agent`، یک ارائه‌دهنده رونویسی بلادرنگ و TTS ‏OpenClaw را پیکربندی کنید؛ یا برای حالت `bidi`، یک ارائه‌دهنده صوتی بلادرنگ را پیکربندی کنید. راهنماهای پلتفرم شامل گزینه‌های ارائه‌دهنده و فرمان صوتی هستند.

## نصب یا غیرفعال‌کردن Pluginها

Google Meet را جداگانه نصب کنید؛ پس از نصب به‌طور پیش‌فرض فعال است. جلسه‌های Teams و Zoom همراه OpenClaw هستند و به‌طور پیش‌فرض فعال‌اند:

```bash
# فقط Google Meet
openclaw plugins install npm:@openclaw/google-meet
```

هر Plugin جلسه‌ای را که استفاده نمی‌کنید غیرفعال کنید:

```bash
openclaw plugins disable google-meet
openclaw plugins disable teams-meetings
openclaw plugins disable zoom-meetings
```

اگر مسیر مدیریت Plugin شما Gateway را به‌طور خودکار راه‌اندازی مجدد نمی‌کند، Gateway را راه‌اندازی مجدد کنید. سپس پیش از پیوستن، بررسی راه‌اندازی پلتفرم را اجرا کنید.

## بررسی و پیوستن

| پلتفرم        | بررسی راه‌اندازی                    | فرمان پیوستن                                                                  |
| --------------- | ------------------------------ | ----------------------------------------------------------------------------- |
| Google Meet     | `openclaw googlemeet setup`    | `openclaw googlemeet join 'https://meet.google.com/abc-defg-hij'`             |
| Microsoft Teams | `openclaw teamsmeetings setup` | `openclaw teamsmeetings join 'https://teams.microsoft.com/l/meetup-join/...'` |
| Zoom            | `openclaw zoommeetings setup`  | `openclaw zoommeetings join 'https://zoom.us/j/1234567890'`                   |

هر بررسی راه‌اندازی ناموفق را برای آن انتقال و حالت، مانع تلقی کنید. برای آزمون دودِ فقط‌مشاهده، حالت `transcribe` را انتخاب کنید و پیش از انتظار متن زیرنویس، تأیید کنید که وضعیت، یک جلسه در حال تماس را گزارش می‌دهد.

برای آزمون‌های دودِ پاسخ صوتی، گفتار تأییدشده به چیزی بیش از پذیرش بایت‌ها توسط فرمان پخش نیاز دارد. پل مشترک جفت‌فرمان، اثرانگشت شکل‌موج محدودِ خروجی تولیدشده فعلی را با صدایی که از مسیر ضبط میکروفون BlackHole بازمی‌گردد هم‌بسته می‌کند؛ Google Meet، ‏Teams و Zoom وقتی فقط شمارنده بایت خروجی افزایش می‌یابد یا صدای نامرتبط شرکت‌کننده وجود دارد، `speechOutputVerified: true` را گزارش نمی‌کنند.

## رسیدگی به درخواست‌های خط‌مشی پلتفرم

خودکارسازی مرورگر، کنترل‌های معمول نام مهمان، دوربین و میکروفون پیش از پیوستن، پیوستن، حین تماس و ترک را مدیریت می‌کند. این خودکارسازی خط‌مشی پلتفرم یا برگزارکننده را دور نمی‌زند.

- Google Meet ممکن است به ورود به حساب گوگل، پذیرش میزبان یا تصمیم‌گیری درباره مجوز مرورگر نیاز داشته باشد.
- Microsoft Teams ممکن است به ورود به حساب مستأجر، تأیید ایمیل یا پذیرش برگزارکننده نیاز داشته باشد.
- Zoom ممکن است به احراز هویت، تأیید ایمیل، رمز ورود، تکمیل CAPTCHA یا پذیرش میزبان نیاز داشته باشد؛ یک حساب همچنین می‌تواند پیوستن از طریق مرورگر را غیرفعال کند.

وقتی نتیجه پیوستن یا وضعیت، `manualActionRequired` را گزارش می‌کند، پیش از تلاش مجدد، مرحله گزارش‌شده را در همان پروفایل Chrome ‏OpenClaw تکمیل کنید. بازکردن مکرر برگه‌های جدید، مانع حساب، مستأجر، لابی یا CAPTCHA را رفع نمی‌کند.

فقط به جلسه‌هایی بپیوندید که اپراتور مجاز است یک عامل به آن‌ها اضافه کند. وقتی خط‌مشی محلی یا قواعد رضایت، افشای مشارکت خودکار، رونویسی یا گفتار مصنوعی را الزامی می‌کنند، شرکت‌کنندگان را مطلع کنید.

## گفت‌وگوی صوتی Discord

[کانال‌های صوتی Discord](/fa/channels/discord#voice-channels) مکالمه بلادرنگ بومی و فقط‌صوتی را بدون خودکارسازی جلسه در مرورگر فراهم می‌کنند. OpenClaw می‌تواند به یک کانال صوتی بپیوندد، گوش دهد، نوبت‌ها را از طریق یک عامل OpenClaw یا مدل صوتی بلادرنگ هدایت کند و پاسخ‌ها را بگوید. حتی وقتی افراد در همان کانال Discord از ویدیو استفاده می‌کنند، این قابلیت ویدیوی دوربین یا اشتراک‌گذاری صفحه را ارسال یا دریافت نمی‌کند؛ بنابراین صدای Discord به‌جای چهارمین Plugin جلسه مرورگری، یک سطح مکالمه زنده مرتبط است.
