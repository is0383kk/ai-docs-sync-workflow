# ClawHub چگونه کار می‌کند

ClawHub لایهٔ رجیستری برای Skills و Pluginهای OpenClaw است. این سامانه فضایی برای
کشف بسته‌ها در اختیار کاربران، فضایی برای انتشار نسخه‌ها در اختیار ناشران و
فرادادهٔ کافی برای نصب و به‌روزرسانی امن آن بسته‌ها در اختیار OpenClaw قرار می‌دهد.

## رکوردهای رجیستری

هر فهرست عمومی یک رکورد رجیستری با موارد زیر است:

- یک مالک و نامک یا نام بسته
- یک یا چند نسخهٔ منتشرشده
- فراداده، خلاصه، فایل‌ها و انتساب منبع
- اطلاعات تغییرات و برچسب، مانند `latest`
- سیگنال‌های دانلود، نصب و ستاره
- وضعیت اسکن امنیتی و نظارت محتوا

صفحهٔ فهرست، مکان مرجع برای بررسی ادعای یک Skill یا
Plugin دربارهٔ کارکردش پیش از نصب آن است.

## Skills

یک Skill، بسته‌ای متنی و نسخه‌بندی‌شده با محوریت `SKILL.md` است. این بسته می‌تواند
شامل فایل‌های پشتیبان، نمونه‌ها، الگوها و اسکریپت‌ها باشد.

ClawHub فرانت‌متر `SKILL.md` را می‌خواند تا نام Skill،
توضیحات، الزامات، متغیرهای محیطی و فرادادهٔ آن را درک کند. فرادادهٔ دقیق
اهمیت دارد، زیرا به کاربران کمک می‌کند دربارهٔ نصب Skill تصمیم بگیرند و
به اسکن‌های خودکار کمک می‌کند مغایرت میان رفتار اعلام‌شده و مشاهده‌شده را تشخیص دهند.

[قالب Skill](/clawhub/skill-format) را ببینید.

## Pluginها

Pluginها افزونه‌های بسته‌بندی‌شدهٔ OpenClaw هستند. ClawHub فرادادهٔ بسته،
اطلاعات سازگاری، پیوندهای منبع، مصنوعات و رکوردهای نسخه را ذخیره می‌کند.

هنگامی که OpenClaw یک Plugin را از ClawHub نصب می‌کند، پیش از نصب
فرادادهٔ سازگاری اعلام‌شده را بررسی می‌کند. رکوردهای بسته می‌توانند شامل سازگاری API،
حداقل نسخهٔ Gateway، میزبان‌های هدف، الزامات محیطی و
چکیده‌های مصنوعات باشند.

هرگاه می‌خواهید رجیستری منبع حقیقت باشد، از یک منبع نصب صریح ClawHub
استفاده کنید:

```bash
openclaw plugins install clawhub:<package>
```

## انتشار

انتشار، یک رکورد نسخهٔ تغییرناپذیر جدید ایجاد می‌کند. ناشران برای گردش‌کارهای احرازهویت‌شدهٔ رجیستری از
CLI ‏`clawhub` استفاده می‌کنند:

```bash
clawhub skill publish ./my-skill
clawhub package publish <source> --family code-plugin --dry-run
clawhub package publish <source> --family code-plugin
```

برای پیش‌نمایش بار دادهٔ نهایی پیش از بارگذاری، از اجرای آزمایشی استفاده کنید. سپس صفحات عمومی
فرادادهٔ منتشرشده، فایل‌ها، انتساب منبع و وضعیت اسکن را
نمایش می‌دهند.

## نصب‌ها و به‌روزرسانی‌ها

فرمان‌های نصب OpenClaw از ClawHub به‌عنوان منبع بسته استفاده می‌کنند:

```bash
openclaw skills install @openclaw/demo
openclaw plugins install clawhub:<package>
```

OpenClaw فرادادهٔ منبع نصب را ثبت می‌کند تا به‌روزرسانی‌ها بعداً بتوانند همان
بستهٔ رجیستری را شناسایی کنند. CLI ‏ClawHub همچنین از گردش‌کارهای مستقیم نصب و
به‌روزرسانی Skill برای کاربرانی پشتیبانی می‌کند که پوشه‌های Skill مدیریت‌شده توسط رجیستری را خارج از یک
فضای کاری کامل OpenClaw می‌خواهند.

## وضعیت امنیتی

ClawHub برای انتشار آزاد است، اما نسخه‌ها همچنان مشمول دروازه‌های بارگذاری،
بررسی‌های خودکار، گزارش‌های کاربران و اقدام ناظران هستند.

صفحات عمومی، در صورت موجود بودن، خلاصه‌های اسکن را نمایش می‌دهند. محتوایی که نگه داشته، پنهان
یا مسدود شده است، ممکن است از جست‌وجوی عمومی و جریان‌های نصب حذف شود، اما برای
مالک با هدف عیب‌یابی قابل‌مشاهده بماند.

[امنیت](/clawhub/security)، [ممیزی‌های امنیتی](/clawhub/security-audits)،
[نظارت محتوا و ایمنی حساب](/clawhub/moderation) و
[استفادهٔ قابل‌قبول](/clawhub/acceptable-usage) را ببینید.

## دسترسی API

ClawHub برای کشف، جست‌وجو، جزئیات بسته و
دانلودها APIهای خواندن عمومی ارائه می‌دهد. کاتالوگ‌های شخص ثالث می‌توانند از این APIها استفاده کنند، مشروط بر اینکه به
فهرست مرجع ClawHub پیوند دهند، محدودیت نرخ را رعایت کنند و از القای تأییدشدن خودداری کنند.

[API عمومی](/clawhub/api) و [API ‏HTTP](/clawhub/http-api) را ببینید.
