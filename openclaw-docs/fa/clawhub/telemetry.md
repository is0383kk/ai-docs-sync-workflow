# تله‌متری

ClawHub از حداقل تله‌متری CLI برای محاسبه تعداد تجمیعی نصب Skills و Pluginها استفاده می‌کند.

## تله‌متری چه زمانی جمع‌آوری می‌شود

تله‌متری فقط زمانی ارسال می‌شود که:

- در CLI وارد حساب شده باشید.
- `clawhub install <slug>` را اجرا کنید، یا نصب احراز هویت‌شده
  `openclaw plugins install clawhub:<package>` را تکمیل کنید.
- تله‌متری **غیرفعال نشده باشد** (بخش «نحوه غیرفعال‌کردن» را در ادامه ببینید).

اگر وارد حساب نشده باشید، هیچ‌چیز گزارش نمی‌شود.

## چه داده‌هایی جمع‌آوری می‌کنیم

پس از نصب یک Skill یا Plugin و ذخیره‌شدن رکورد نصب محلی آن، CLI
یک رویداد نصب را به‌صورت بهترین تلاش ممکن ارسال می‌کند.

این رویداد شامل موارد زیر است:

- نامک Skill نصب‌شده یا نام متعارف بسته Plugin.
- `version`: نسخه نصب‌شده، در صورت مشخص‌بودن.

### چه داده‌هایی را جمع‌آوری _نمی‌کنیم_

- هیچ مسیر پوشه یا شناسه مشتق‌شده از پوشه‌ای.
- هیچ محتوای فایلی.
- هیچ گزارش اجرای منفرد، پرامپت یا خروجی دیگری از CLI.

## تعداد نصب‌ها

ClawHub برای Skills موارد زیر را نگه‌داری می‌کند:

- `installsAllTime`: کاربران منحصربه‌فردی که دست‌کم یک نصب CLI برای Skill را گزارش کرده‌اند.
- `installsCurrent`: کاربران منحصربه‌فردی که نصبی را گزارش کرده‌اند و داده‌های تله‌متری خود را
  حذف نکرده‌اند.

برای Pluginها، ClawHub نخستین نصب موفق گزارش‌شده توسط هر کاربر برای هر بسته را محاسبه می‌کند.
نصب‌ها و به‌روزرسانی‌های تکراری، نسخه ثبت‌شده را بدون افزایش تعداد تجمیعی
نصب به‌روزرسانی می‌کنند.

## شفافیت و کنترل‌های کاربر

همه فقط **شمارنده‌های تجمیعی نصب** را می‌بینند.

حذف حساب شما، داده‌های تله‌متری‌تان را نیز حذف می‌کند و سهم آن را از شمارنده‌های
نصب برمی‌دارد.

## نحوه غیرفعال‌کردن تله‌متری

متغیر محیطی زیر را تنظیم کنید:

```bash
export CLAWHUB_DISABLE_TELEMETRY=1
```

با تنظیم این متغیر، CLI تله‌متری نصب را ارسال نمی‌کند.
