# احراز هویت

ClawHub برای ورود در وب از GitHub استفاده می‌کند. CLI از توکن‌های API در ClawHub استفاده می‌کند که
از طریق همان حساب واردشده ایجاد می‌شوند.

## ورود در وب

برای ورود به [clawhub.ai](https://clawhub.ai) از GitHub استفاده کنید.

حساب‌های حذف‌شده، مسدودشده یا غیرفعال نمی‌توانند فرایند معمول ورود به ClawHub را تکمیل کنند.
اگر پس از ورود دوباره به حالت خارج‌شده از حساب بازمی‌گردید، ممکن است حساب شما از
وضعیت مناسبی برخوردار نباشد. اگر حساب شما مسدود یا غیرفعال شده است و گمان می‌کنید این
اشتباهی رخ داده است، از
[فرم درخواست تجدیدنظر ClawHub](https://appeals.openclaw.ai/) استفاده کنید.

## ورود به CLI

فرایند پیش‌فرض ورود به CLI مرورگر را باز می‌کند:

```bash
clawhub login
clawhub whoami
```

آنچه رخ می‌دهد:

1. CLI یک سرور موقت بازگشت فراخوانی را روی `127.0.0.1` راه‌اندازی می‌کند.
2. مرورگر شما صفحه ورود ClawHub را باز می‌کند.
3. پس از ورود با GitHub، ClawHub یک توکن API ایجاد می‌کند.
4. مرورگر به بازگشت فراخوانی محلی هدایت می‌شود.
5. CLI توکن را در فایل پیکربندی ClawHub شما ذخیره می‌کند.

اگر مرورگر به‌دلیل قواعد فایروال، VPN یا پراکسی نمی‌تواند به بازگشت فراخوانی محلی دسترسی پیدا کند،
از فرایند توکن بدون رابط گرافیکی استفاده کنید.

## ورود بدون رابط گرافیکی

یک توکن در رابط وب ClawHub ایجاد کنید، سپس آن را به CLI بدهید:

```bash
clawhub login --token clh_...
```

از این فرایند برای سرورها، کارهای CI یا محیط‌های صرفاً مبتنی بر ترمینال استفاده کنید.

برای پوسته‌های راه دوری که می‌توانید مرورگر را در جای دیگری باز کنید، اجرا کنید:

```bash
clawhub login --device
```

CLI یک کد یک‌بارمصرف نمایش می‌دهد و در مدتی که آن را در
`https://clawhub.ai/cli/device` مجاز می‌کنید، منتظر می‌ماند.

## ذخیره‌سازی توکن

مسیرهای پیش‌فرض پیکربندی:

- macOS: `~/Library/Application Support/clawhub/config.json`
- Linux/XDG: `$XDG_CONFIG_HOME/clawhub/config.json` یا `~/.config/clawhub/config.json`
- Windows: `%APPDATA%\\clawhub\\config.json`

مسیر را به این صورت بازنویسی کنید:

```bash
export CLAWHUB_CONFIG_PATH=/path/to/config.json
```

برای راه‌اندازی CI، توکن ذخیره‌شده را با این فرمان نمایش دهید:

```bash
clawhub token
```

## ابطال

می‌توانید توکن‌های API را در رابط وب ClawHub باطل کنید.

توکن‌های باطل‌شده، نامعتبر یا مفقود، `401 Unauthorized` را برمی‌گردانند. دوباره
با `clawhub login` وارد شوید یا با `clawhub login --token` یک توکن تازه ارائه کنید.

حساب‌های حذف‌شده، مسدودشده یا غیرفعال نمی‌توانند به استفاده از توکن‌های API موجود ادامه دهند.
اگر حساب شما مسدود یا غیرفعال شده است و گمان می‌کنید این
اشتباهی رخ داده است، از
[فرم درخواست تجدیدنظر ClawHub](https://appeals.openclaw.ai/) استفاده کنید.
