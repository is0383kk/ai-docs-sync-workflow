# `openclaw dashboard`

رابط کاربری کنترل را با احراز هویت فعلی خود باز کنید.

```bash
openclaw dashboard
openclaw dashboard --no-open
openclaw dashboard --json
openclaw dashboard --yes
```

- `--no-open`: نشانی URL را چاپ می‌کند، اما مرورگر را اجرا نمی‌کند.
- `--json`: بدون بازکردن مرورگر، استفاده از کلیپ‌بورد، نمایش درخواست ورودی یا راه‌اندازی Gateway، یک شیء اتصال ماشین‌خوان را چاپ می‌کند.
- `--yes`: در صورت نیاز، Gateway را بدون نمایش درخواست ورودی راه‌اندازی/نصب می‌کند.

## خروجی ماشین‌خوان

برای یکپارچه‌سازی‌های دسکتاپ و اسکریپت‌هایی که به نشانی URL نهایی رابط کاربری کنترل نیاز دارند، از `--json` استفاده کنید:

```bash
openclaw dashboard --json
```

پاسخ شامل `url`، `httpUrl`، `wsUrl`، `port` و `tokenIncluded` است. اگر Gateway آماده نباشد، فرمان `{"ok":false,"reason":"..."}` را برمی‌گرداند و با کد خروج غیرصفر خاتمه می‌یابد. توکن‌های مدیریت‌شده با SecretRef هرگز در `url` گنجانده نمی‌شوند.

نکته‌ها:

- در صورت امکان، SecretRefهای پیکربندی‌شدهٔ `gateway.auth.token` را برطرف می‌کند.
- از `gateway.tls.enabled` پیروی می‌کند: Gatewayهای دارای TLS نشانی‌های URL رابط کاربری کنترل `https://` را چاپ/باز می‌کنند و از طریق `wss://` متصل می‌شوند.
- برای اتصال `lan` یا اتصال با نویسهٔ عام `custom`، اجراها روی همان میزبان همیشه از loopback استفاده می‌کنند، زیرا نویسهٔ عام مقصد مرورگر نیست. اتصال‌های متن سادهٔ `tailnet` و `custom` نیز از `127.0.0.1` استفاده می‌کنند تا مرورگر زمینه‌ای امن داشته باشد؛ میزبان‌های مشخص دارای TLS نشانی پیکربندی‌شده را حفظ می‌کنند تا نام‌های گواهی مطابقت داشته باشند.
- پیش از ارائهٔ نشانی URL احرازشدهٔ loopback برای اتصال به یک رابط مشخص، فرمان رابط پیکربندی‌شده را بررسی می‌کند و اطمینان می‌یابد که آن رابط و `127.0.0.1` متعلق به یک فرایند Gateway هستند. در صورت مبهم‌بودن مالکیت شنونده، عملیات به‌صورت ایمن متوقف می‌شود و راهنمای وضعیت ارائه می‌گردد.
- برای توکن‌های مدیریت‌شده با SecretRef (برطرف‌شده یا برطرف‌نشده)، نشانی URL چاپ‌شده/کپی‌شده/بازشده هرگز شامل توکن نیست؛ بنابراین اسرار خارجی در خروجی ترمینال، تاریخچهٔ کلیپ‌بورد یا آرگومان‌های اجرای مرورگر افشا نمی‌شوند.
- اگر `gateway.auth.token` با SecretRef مدیریت شود اما برطرف نشده باشد، فرمان به‌جای یک جای‌نگهدار نامعتبر توکن، نشانی URL بدون توکن و راهنمای رفع مشکل را چاپ می‌کند.
- اگر ارائه از طریق کلیپ‌بورد/مرورگر برای نشانی URL دارای احراز هویت توکنی ناموفق باشد، فرمان بدون چاپ مقدار توکن، یک راهنمای امن برای احراز هویت دستی ثبت می‌کند که `OPENCLAW_GATEWAY_TOKEN`، `gateway.auth.token` و کلید قطعهٔ URL یعنی `token` را نام می‌برد.
