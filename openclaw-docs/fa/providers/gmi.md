GMI Cloud یک پلتفرم استنتاج میزبانی‌شده برای مدل‌های پیشرو و دارای وزن‌های باز است
که پشت یک API سازگار با OpenAI قرار دارد. در OpenClaw، این پلتفرم یک Plugin رسمی ارائه‌دهنده خارجی
است: آن را یک‌بار نصب کنید، اطلاعات احراز هویت را از طریق احراز هویت معمول مدل ذخیره کنید و از
ارجاع‌های مدل مانند `gmi/google/gemini-3.1-flash-lite` استفاده کنید.

هنگامی از GMI استفاده کنید که برای چندین خانواده مدل میزبانی‌شده، از جمله
مسیرهای Anthropic، DeepSeek، Google، Moonshot، OpenAI و Z.AI که در
کاتالوگ GMI ارائه می‌شوند، یک کلید API می‌خواهید. می‌توان از آن به‌عنوان ارائه‌دهنده ثانویه برای بازگشت مدل، مقایسه
مسیرهای میزبانی‌شده میان عرضه‌کنندگان یا هنگامی استفاده کرد که مدلی در GMI پیش از
ارائه‌دهنده اصلی شما در دسترس است. OpenClaw مالک شناسه ارائه‌دهنده، پروفایل احراز هویت، نام‌های مستعار،
بذر کاتالوگ مدل و URL پایه است؛ GMI مالک دسترس‌پذیری زنده مدل‌ها، صورت‌حساب،
محدودیت‌های نرخ و هرگونه خط‌مشی مسیریابی سمت ارائه‌دهنده است.

| ویژگی      | مقدار                                    |
| ------------- | ---------------------------------------- |
| شناسه ارائه‌دهنده   | `gmi` (نام‌های مستعار: `gmi-cloud`، `gmicloud`) |
| بسته       | `@openclaw/gmi-provider`                 |
| متغیر محیطی احراز هویت  | `GMI_API_KEY`                            |
| API           | سازگار با OpenAI (`openai-completions`) |
| URL پایه      | `https://api.gmi-serving.com/v1`         |
| مدل پیش‌فرض | `gmi/google/gemini-3.1-flash-lite`       |

## راه‌اندازی

Plugin را نصب کنید، Gateway را راه‌اندازی مجدد کنید، سپس یک کلید API در GMI Cloud
ایجاد کنید (`https://www.gmicloud.ai/`):

```bash
openclaw plugins install @openclaw/gmi-provider
openclaw gateway restart
```

سپس اجرا کنید:

```bash
openclaw onboard --auth-choice gmi-api-key
```

راه‌اندازی‌های غیرتعاملی می‌توانند `--gmi-api-key <key>` را ارسال کنند یا مقدار زیر را تنظیم کنند:

```bash
export GMI_API_KEY="<your-gmi-api-key>" # pragma: allowlist secret
```

## چه زمانی GMI را انتخاب کنید

- به‌جای سرور مدل محلی، یک نقطه پایانی میزبانی‌شده سازگار با OpenAI می‌خواهید.
- می‌خواهید چندین خانواده مدل تجاری و دارای وزن‌های باز را از طریق یک
  حساب ارائه‌دهنده امتحان کنید.
- یک ارائه‌دهنده بازگشت با مسیریابی بالادستی متفاوت از DeepInfra،
  OpenRouter، Together یا APIهای مستقیم عرضه‌کنندگان می‌خواهید.
- به شناسه‌های مدل، قیمت‌گذاری یا کنترل‌های حساب مختص GMI نیاز دارید.

هنگامی که به قابلیت‌های بومی عرضه‌کننده نیاز دارید که GMI آن‌ها را از طریق مسیر سازگار با OpenAI خود
ارائه نمی‌کند، ارائه‌دهنده مستقیم آن عرضه‌کننده را انتخاب کنید. هنگامی که محلی‌بودن
داده‌ها یا کنترل GPU محلی مهم‌تر از سهولت میزبانی‌شده است، یک ارائه‌دهنده محلی
مانند LM Studio، Ollama، SGLang یا vLLM را انتخاب کنید.

## مدل‌ها

کاتالوگ Plugin، شناسه‌های مسیر رایج GMI Cloud را بذرگذاری می‌کند:

| ارجاع مدل                          | ورودی        | زمینه   | حداکثر خروجی |
| ---------------------------------- | ------------ | --------- | ---------- |
| `gmi/anthropic/claude-sonnet-4.6`  | متن + تصویر | 200,000   | 64,000     |
| `gmi/deepseek-ai/DeepSeek-V3.2`    | متن         | 163,840   | 65,536     |
| `gmi/google/gemini-3.1-flash-lite` | متن + تصویر | 1,048,576 | 65,536     |
| `gmi/moonshotai/Kimi-K2.5`         | متن + تصویر | 262,144   | 65,536     |
| `gmi/openai/gpt-5.4`               | متن + تصویر | 400,000   | 128,000    |
| `gmi/zai-org/GLM-5.1-FP8`          | متن         | 202,752   | 65,536     |

کاتالوگ یک بذر است، نه تضمینی مبنی بر اینکه هر حسابی بتواند در
همه زمان‌ها هر مدلی را فراخوانی کند. مواردی را که ارائه‌دهنده پیکربندی‌شده در محیط شما گزارش می‌دهد، فهرست کنید:

```bash
openclaw models list --provider gmi
```

## عیب‌یابی

- `401` یا `403`: بررسی کنید که `GMI_API_KEY` برای فرایندی که
  OpenClaw را اجرا می‌کند تنظیم شده باشد، یا فرایند راه‌اندازی اولیه را دوباره اجرا کنید تا کلید در پروفایل احراز هویت ارائه‌دهنده ذخیره شود.
- خطاهای مدل ناشناخته: تأیید کنید که مدل در حساب GMI شما وجود دارد و از
  ارجاع کامل `gmi/<route-id>` نمایش‌داده‌شده توسط `openclaw models list --provider gmi` استفاده کنید.
- خطاهای متناوب ارائه‌دهنده: مسیر دیگری از GMI را امتحان کنید یا GMI را به‌جای
  تنها ارائه‌دهنده مدل اصلی، به‌عنوان ارائه‌دهنده بازگشت پیکربندی کنید.
