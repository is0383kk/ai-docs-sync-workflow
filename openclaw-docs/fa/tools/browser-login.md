## ورود دستی (توصیه‌شده)

هنگامی که سایتی نیازمند ورود است، به‌صورت دستی در پروفایل `openclaw`
مرورگر میزبان وارد شوید. اطلاعات احراز هویت خود را در اختیار مدل قرار ندهید: ورودهای خودکار اغلب
سازوکارهای ضدربات را فعال می‌کنند و ممکن است حساب را قفل کنند.

برای خواندن (جست‌وجو/رشته‌گفت‌وگوها) و
انتشار مطلب در X/Twitter و دیگر سایت‌های حساس به ربات، از مرورگر میزبان (ورود دستی) استفاده کنید. نشست‌های مرورگر سندباکس‌شده
با احتمال بیشتری تشخیص ربات را فعال می‌کنند.

بازگشت به مستندات اصلی مرورگر: [مرورگر](/fa/tools/browser).

## از کدام پروفایل Chrome استفاده می‌شود؟

OpenClaw یک پروفایل اختصاصی Chrome با نام `openclaw` (با
رابط کاربری نارنجی‌رنگ) را کنترل می‌کند که از پروفایل مرورگر روزمره شما جدا است.

برای فراخوانی‌های ابزار مرورگر عامل:

- انتخاب پیش‌فرض: عامل از مرورگر ایزوله `openclaw` خود استفاده می‌کند.
- فقط هنگامی از `profile="user"` استفاده کنید که نشست‌های واردشده موجود اهمیت دارند و شما
  پشت رایانه هستید تا روی هر درخواست اتصال کلیک کنید یا آن را تأیید کنید.
- اگر چند پروفایل مرورگر کاربر دارید، به‌جای حدس‌زدن، پروفایل را به‌صراحت
  مشخص کنید.

دو راه برای دسترسی به پروفایل `openclaw`:

1. از عامل بخواهید مرورگر را باز کند، سپس خودتان وارد شوید.
2. آن را از طریق CLI باز کنید:

```bash
openclaw browser start
openclaw browser open https://x.com
```

برای پروفایلی غیر از پیش‌فرض، `--browser-profile <name>` را پیش از
زیرفرمان قرار دهید (پیش‌فرض `openclaw` است):

```bash
openclaw browser --browser-profile <name> open https://x.com
```

## سندباکس‌سازی: اجازه دسترسی به مرورگر میزبان

اگر عامل در سندباکس باشد، فراخوانی‌های ابزار `browser` آن به‌طور پیش‌فرض مرورگر
سندباکس را هدف می‌گیرند، نه میزبان را. برای اینکه عامل بتواند به‌جای آن مرورگر میزبان را هدف بگیرد:

```json5
{
  agents: {
    defaults: {
      sandbox: {
        mode: "non-main",
        browser: {
          allowHostControl: true,
        },
      },
    },
  },
}
```

فراخوانی‌های CLI همیشه مرورگر میزبان را هدف می‌گیرند، نه سندباکس را؛ بنابراین
صرف‌نظر از این تنظیم می‌توانید خودتان مرورگر میزبان را باز کنید:

```bash
openclaw browser --browser-profile openclaw open https://x.com
```

پس از تنظیم `sandbox.browser.allowHostControl: true`، فراخوانی‌های ابزار `browser`
عامل نیز می‌توانند میزبان را هدف بگیرند. راه دیگر این است که سندباکس‌سازی را برای
عاملی که به‌روزرسانی‌ها را منتشر می‌کند غیرفعال کنید.
