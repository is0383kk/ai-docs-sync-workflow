ویژگی‌های آزمایشی سطوح پیش‌نمایشی هستند که پشت پرچم‌های صریح قرار دارند. آن‌ها پیش از دستیابی به یک مقدار پیش‌فرض پایدار یا قراردادی بلندمدت، به استفادهٔ عملی بیشتری در دنیای واقعی نیاز دارند.

- به‌طور پیش‌فرض خاموش است، مگر اینکه سندی یک قاعدهٔ محدود برای راه‌اندازی خودکار را توضیح دهد.
- ساختار و رفتار می‌توانند سریع‌تر از پیکربندی پایدار تغییر کنند.
- وقتی از قبل مسیری پایدار وجود دارد، آن را ترجیح دهید.
- تنها پس از آزمایش اولیه در محیطی کوچک‌تر، آن را به‌طور گسترده عرضه کنید.

## Labs رابط کاربری Control

برای مدیریت آزمایش‌هایی که در رابط کاربری Control کلید دارند، **Settings → Agents & Tools → Labs** را باز کنید. فعال یا غیرفعال‌کردن یک آزمایش، پیکربندی مرجع Gateway را
بی‌درنگ اصلاح می‌کند؛ صفحه تنها زمانی راهنمای راه‌اندازی مجدد را نشان می‌دهد که یک ویژگی
به آن نیاز داشته باشد.

Code Mode و Swarm ورودی‌های فعلی عرضه‌شده در Labs هستند. هر دو کلید
کلیدهای پیکربندی معتبر موجود را می‌نویسند و معمولاً بدون راه‌اندازی مجدد Gateway، برای اجراهای آیندهٔ عامل
اعمال می‌شوند.

## حالت سبک مدل محلی

`agents.defaults.experimental.localModelLean: true` در هر نوبت، ابزارهای اختیاری سنگین را از سطح مستقیم عامل حذف می‌کند: `browser`، `cron`، `message`، `image_generate`، `music_generate`، `video_generate`، `tts` و `pdf`. ابزارهایی که صراحتاً مجازند یا برای تحویل لازم‌اند همچنان در دسترس می‌مانند، هرچند Tool Search ممکن است آن‌ها را به‌جای نمایش مستقیم، فهرست‌بندی کند. حالت سبک همچنین در صورتی که `tools.toolSearch` از قبل تنظیم نشده باشد، فهرست‌های plugin/MCP/client را به‌طور پیش‌فرض روی Tool Search ساخت‌یافته (`tool_search`، `tool_describe`، `tool_call`) قرار می‌دهد. برای محدودکردن این تنظیم به یک عامل، از `agents.entries.*.experimental.localModelLean` استفاده کنید.

هنگام ورود اولیه، یک مسیر استنتاج تأییدشدهٔ `ollama` یا `lmstudio` در صورت نبود آن مقدار، به‌طور خودکار `agents.defaults.experimental.localModelLean: true` را تنظیم می‌کند. OpenClaw ثبت می‌کند که این تنظیم از ورود اولیه آمده است؛ بنابراین مسیر غیرمحلی تأییدشده‌ای که بعداً اضافه شود، تنها تنظیم خودکار را برمی‌دارد. `true` یا `false` که صراحتاً پیکربندی شده باشد حفظ می‌شود. سایر ارائه‌دهندگان خودمیزبان و سازگار با OpenAI از روی نام مدل‌ها یا URLها استنباط نمی‌شوند.

اگر Tool Search را از قبل به‌صورت سراسری تنظیم کرده‌اید، OpenClaw آن پیکربندی را بدون تغییر نگه می‌دارد. برای انصراف از مقدار پیش‌فرض Tool Search در حالت سبک، `tools.toolSearch: false` را تنظیم کنید.

در حالت ساخت‌یافتهٔ `tools`، اجراهای سبک `exec` را مستقیماً کنار کنترل‌های Tool Search قابل‌مشاهده نگه می‌دارند تا مدل‌های محلی بهینه‌شده برای کدنویسی همچنان بتوانند مسیر شل آشنای خود را انتخاب کنند. این فقط قابلیت مشاهدهٔ طرح‌واره را تغییر می‌دهد: سیاست عادی ابزار، سندباکس‌سازی و تأییدهای اجرا همچنان اعمال می‌شوند. حالت‌های صریح `code` و `directory` رفتار عادی Compaction خود را حفظ می‌کنند.

### چرا این ابزارها

این ابزارها طولانی‌ترین توضیحات، گسترده‌ترین ساختارهای پارامتر یا بیشترین احتمال منحرف‌کردن یک مدل کوچک از مسیر عادی کدنویسی و مکالمه را دارند. در یک بک‌اند با زمینهٔ کوچک یا سازگار با OpenAI و سخت‌گیرتر، تفاوت میان این حالت‌ها چنین است:

- جاگرفتن طرح‌واره‌های ابزار در پرامپت در برابر کنارزدن تاریخچهٔ مکالمه.
- انتخاب ابزار درست توسط مدل در برابر تولید فراخوانی‌های بدساخت ابزار به‌دلیل وجود طرح‌واره‌های مشابه بیش‌ازحد.
- باقی‌ماندن آداپتور Chat Completions در محدوده‌های خروجی ساخت‌یافته در برابر دریافت خطای 400 به‌علت اندازهٔ بار فراخوانی ابزار.

حذف آن‌ها فقط فهرست مستقیم ابزارها را کوتاه‌تر می‌کند. مدل همچنان به `read`، `write`، `edit`، `exec`، `apply_patch`، درک تصویر، جست‌وجو/واکشی وب (در صورت پیکربندی)، حافظه و ابزارهای نشست/عامل دسترسی دارد. فهرست‌های اضافی از طریق Tool Search همچنان قابل‌دسترسی‌اند، مگر اینکه `tools.toolSearch: false` را تنظیم کنید؛ مجوزهای صریح ابزار می‌توانند یک عامل سبک را دوباره وارد یک گردش‌کار محدودشده کنند.

### چه زمانی آن را روشن کنید

پس از آنکه ثابت کردید مدل می‌تواند با Gateway ارتباط برقرار کند اما نوبت‌های کامل عامل درست رفتار نمی‌کنند، حالت سبک را فعال کنید:

1. `openclaw infer model run --gateway --model <ref> --prompt "Reply with exactly: pong"` موفق می‌شود.
2. یک نوبت عادی عامل با فراخوانی‌های بدساخت ابزار، پرامپت‌های بیش‌ازحد بزرگ یا نادیده‌گرفتن ابزارها توسط مدل شکست می‌خورد.
3. تغییر وضعیت `localModelLean: true` خطا را برطرف می‌کند.

### چه زمانی آن را خاموش نگه دارید

اگر بک‌اند شما زمان‌اجرای کامل پیش‌فرض را بدون مشکل مدیریت می‌کند، این گزینه را خاموش نگه دارید. این یک راهکار موقت برای پشته‌های محلی است که به سطح ابزار کوچک‌تری نیاز دارند، نه یک مقدار پیش‌فرض برای مدل‌های میزبانی‌شده یا سامانه‌های محلی برخوردار از منابع کافی.

حالت سبک جایگزین `tools.profile`، `tools.allow`/`tools.deny` یا راه گریز `compat.supportsTools: false` مدل نمی‌شود. برای ایجاد یک سطح ابزار باریک‌تر و دائمی روی عاملی مشخص، آن کنترل‌های پایدار را ترجیح دهید.

### فعال‌سازی

```json5
{
  agents: {
    defaults: {
      experimental: {
        localModelLean: true,
      },
    },
  },
}
```

فقط برای یک عامل:

```json5
{
  agents: {
    list: [
      {
        id: "local",
        model: "lmstudio/gemma-4-e4b-it",
        experimental: {
          localModelLean: true,
        },
      },
    ],
  },
}
```

پس از تغییر پرچم، Gateway را راه‌اندازی مجدد کنید. پالایش حالت سبک، `browser`، `cron`، `message`، `image_generate`، `music_generate`، `video_generate`، `tts` و `pdf` را حذف می‌کند، مگر اینکه آن‌ها را صراحتاً با `tools.allow` یا `tools.alsoAllow` حفظ کنید؛ Tool Search ممکن است همچنان ابزارهای حفظ‌شده را به‌جای نمایش مستقیم، فهرست‌بندی کند.

## آزمایشی به‌معنای پنهان نیست

یک ویژگی آزمایشی باید در مستندات و خود مسیر پیکربندی به‌روشنی آزمایشی‌بودن خود را بیان کند، نه اینکه پشت کنترلی با ظاهر پایدار و پیش‌فرض پنهان شود.
