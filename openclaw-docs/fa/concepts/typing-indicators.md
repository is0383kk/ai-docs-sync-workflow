نشانگرهای تایپ هنگام فعال بودن یک اجرا به کانال چت ارسال می‌شوند. از `agents.defaults.typingMode` برای کنترل **زمان** آغاز تایپ و از `typingIntervalSeconds` برای کنترل **دفعات** تازه‌سازی آن استفاده کنید (تناوب زنده‌نگه‌داشتن، پیش‌فرض 6 ثانیه).

## پیش‌فرض‌ها

وقتی `agents.defaults.typingMode` **تنظیم نشده است**:

- **چت‌های مستقیم**: به‌محض آغاز حلقه مدل، تایپ فوراً شروع می‌شود.
- **چت‌های گروهی دارای اشاره**: تایپ فوراً شروع می‌شود.
- **چت‌های گروهی بدون اشاره**: تایپ زمانی شروع می‌شود که اجرای پذیرفته‌شده فعالیتی قابل‌مشاهده برای کاربر داشته باشد، مانند فعالیت اجرای هارنس یا متن پیام.
- **اجراهای Heartbeat**: اگر مقصد Heartbeat تعیین‌شده چتی با قابلیت نمایش تایپ باشد و تایپ غیرفعال نشده باشد، تایپ هنگام آغاز اجرای Heartbeat شروع می‌شود.

## حالت‌ها

`agents.defaults.typingMode` را روی یکی از موارد زیر تنظیم کنید:

- `never` - هیچ‌گاه نشانگر تایپ نمایش داده نمی‌شود.
- `instant` - تایپ را **به‌محض آغاز حلقه مدل** شروع می‌کند، حتی اگر اجرا بعداً فقط توکن پاسخ بی‌صدا را برگرداند.
- `thinking` - تایپ را با **اولین دلتای استدلال** یا پس از پذیرفته‌شدن نوبت، هنگام اجرای فعال هارنس شروع می‌کند.
- `message` - تایپ را با **اولین فعالیت پاسخ قابل‌مشاهده برای کاربر**، مانند اجرای فعال هارنس یا یک دلتای متنی غیربی‌صدا شروع می‌کند. توکن‌های پاسخ بی‌صدا مانند `NO_REPLY` فعالیت متنی محسوب نمی‌شوند.

ترتیب «میزان زودهنگام فعال‌شدن»: `never` -> `message`/`thinking` -> `instant`.

## پیکربندی

پیش‌فرض سطح عامل را تنظیم کنید:

```json5
{
  agents: {
    defaults: {
      typingMode: "thinking",
      typingIntervalSeconds: 6,
    },
  },
}
```

سیاست را برای یک عامل بازنویسی کنید:

```json5
{
  agents: {
    entries: {
      support: {
        typingMode: "message",
      },
    },
  },
}
```

## نکات

- حالت `message` با توکن‌های پاسخ بی‌صدا شروع نمی‌شود، اما اجرای فعال همچنان می‌تواند پیش از در دسترس بودن هرگونه متن دستیار، تایپ را نمایش دهد.
- `thinking` همچنان به استدلال جریانی (`reasoningLevel: "stream"`) واکنش نشان می‌دهد و همچنین می‌تواند پیش از رسیدن دلتاهای استدلال، با اجرای فعال شروع شود.
- تایپ Heartbeat یک سیگنال زنده‌بودن برای مقصد تحویل تعیین‌شده است. این تایپ هنگام آغاز اجرای Heartbeat شروع می‌شود، نه بر اساس زمان‌بندی جریان `message` یا `thinking`. برای غیرفعال‌کردن آن، `typingMode: "never"` را تنظیم کنید.
- وقتی مقصد Heartbeat برابر با `"none"` باشد، مقصد قابل تعیین نباشد، تحویل چت برای Heartbeat غیرفعال باشد یا کانال از تایپ پشتیبانی نکند، Heartbeatها تایپ را نمایش نمی‌دهند.
- `agents.defaults.typingIntervalSeconds` **تناوب تازه‌سازی** را برای همه عامل‌ها کنترل می‌کند، نه زمان آغاز را. پیش‌فرض: 6 ثانیه.
