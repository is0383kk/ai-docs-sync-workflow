[Honcho](https://honcho.dev) حافظه بومی هوش مصنوعی را از طریق یک
Plugin خارجی به OpenClaw اضافه می‌کند. این افزونه مکالمات را در سرویسی اختصاصی ماندگار می‌کند و
به‌مرور زمان مدل‌هایی از کاربر و عامل می‌سازد؛ در نتیجه، زمینه‌ای میان‌نشستی در اختیار عامل قرار می‌دهد که
فراتر از فایل‌های Markdown فضای کاری است.

## امکانات ارائه‌شده

- **حافظه میان‌نشستی** - مکالمات پس از هر نوبت ماندگار می‌شوند؛ بنابراین
  زمینه در بازنشانی نشست، Compaction و جابه‌جایی میان کانال‌ها حفظ می‌شود.
- **مدل‌سازی کاربر** - Honcho برای هر کاربر نمایه‌ای شامل ترجیحات،
  واقعیت‌ها و سبک ارتباطی و برای عامل نمایه‌ای شامل شخصیت و رفتارهای
  آموخته‌شده نگه‌داری می‌کند.
- **جست‌وجوی معنایی** - جست‌وجو در مشاهدات حاصل از مکالمات گذشته، نه
  فقط نشست فعلی.
- **آگاهی چندعاملی** - عامل‌های والد به‌طور خودکار زیرعامل‌های
  ایجادشده را ردیابی می‌کنند و والدها به‌عنوان ناظر به نشست‌های فرزند افزوده می‌شوند.

## ابزارهای موجود

Honcho ابزارهایی ثبت می‌کند که عامل می‌تواند هنگام مکالمه از آن‌ها استفاده کند:

**بازیابی داده‌ها (سریع، بدون فراخوانی LLM):**

| ابزار                        | کاری که انجام می‌دهد                                           |
| --------------------------- | ------------------------------------------------------ |
| `honcho_context`            | بازنمایی کامل کاربر در همه نشست‌ها               |
| `honcho_search_conclusions` | جست‌وجوی معنایی در نتیجه‌گیری‌های ذخیره‌شده                |
| `honcho_search_messages`    | یافتن پیام‌ها در نشست‌ها (فیلتر براساس فرستنده و تاریخ) |
| `honcho_session`            | تاریخچه و خلاصه نشست فعلی                    |

**پرسش و پاسخ (مبتنی بر LLM):**

| ابزار         | کاری که انجام می‌دهد                                                              |
| ------------ | ------------------------------------------------------------------------- |
| `honcho_ask` | پرسش درباره کاربر. `depth='quick'` برای واقعیت‌ها، `'thorough'` برای ترکیب اطلاعات |

## شروع به کار

Plugin را نصب و راه‌اندازی را اجرا کنید:

```bash
openclaw plugins install @honcho-ai/openclaw-honcho
openclaw honcho setup
openclaw gateway --force
```

فرمان راه‌اندازی اطلاعات احراز هویت API را درخواست می‌کند، پیکربندی را می‌نویسد و
در صورت تمایل، فایل‌های حافظه موجود در فضای کاری را مهاجرت می‌دهد.

<Info>
Honcho می‌تواند کاملاً به‌صورت محلی (میزبانی‌شده توسط خودتان) یا از طریق API مدیریت‌شده در
`api.honcho.dev` اجرا شود. گزینه خودمیزبان به هیچ وابستگی خارجی
نیاز ندارد.
</Info>

## پیکربندی

تنظیمات زیر `plugins.entries["openclaw-honcho"].config` قرار دارند:

```json5
{
  plugins: {
    entries: {
      "openclaw-honcho": {
        config: {
          apiKey: "your-api-key", // برای حالت خودمیزبان حذف شود
          workspaceId: "openclaw", // جداسازی حافظه
          baseUrl: "https://api.honcho.dev",
        },
      },
    },
  },
}
```

برای نمونه‌های خودمیزبان، `baseUrl` را به سرور محلی خود هدایت کنید (برای مثال
`http://localhost:8000`) و کلید API را حذف کنید.

## مهاجرت حافظه موجود

اگر فایل‌های حافظه موجود در فضای کاری دارید (`USER.md`، `MEMORY.md`،
`IDENTITY.md`، `memory/`، `canvas/`)، `openclaw honcho setup` آن‌ها را شناسایی می‌کند و
گزینه مهاجرتشان را ارائه می‌دهد.

<Info>
مهاجرت غیرمخرب است؛ فایل‌ها در Honcho بارگذاری می‌شوند. فایل‌های اصلی
هرگز حذف یا جابه‌جا نمی‌شوند.
</Info>

## نحوه کار

پس از هر نوبت هوش مصنوعی، مکالمه در Honcho ماندگار می‌شود. پیام‌های کاربر و
عامل هر دو مشاهده می‌شوند تا Honcho بتواند به‌مرور زمان مدل‌های خود را بسازد و
بهبود دهد.

هنگام مکالمه، ابزارهای Honcho در هوک Plugin با نام
`before_prompt_build` در OpenClaw سرویس را پرس‌وجو می‌کنند و پیش از آنکه مدل
پرامپت را ببیند، زمینه مرتبط را تزریق می‌کنند.

## مقایسه Honcho با حافظه داخلی

|                   | داخلی / QMD                | Honcho                              |
| ----------------- | ---------------------------- | ----------------------------------- |
| **ذخیره‌سازی**       | فایل‌های Markdown فضای کاری     | سرویس اختصاصی (محلی یا میزبانی‌شده) |
| **میان‌نشستی** | از طریق فایل‌های حافظه             | خودکار و داخلی                 |
| **مدل‌سازی کاربر** | دستی (نوشتن در MEMORY.md)  | نمایه‌های خودکار                  |
| **جست‌وجو**        | برداری + کلیدواژه‌ای (ترکیبی)    | معنایی در مشاهدات          |
| **چندعاملی**   | ردیابی نمی‌شود                  | آگاهی از رابطه والد/فرزند              |
| **وابستگی‌ها**  | بدون وابستگی (داخلی) یا فایل اجرایی QMD | نصب Plugin                      |

Honcho و سامانه حافظه داخلی می‌توانند در کنار یکدیگر کار کنند. وقتی QMD
پیکربندی شده باشد، ابزارهای بیشتری برای جست‌وجوی فایل‌های Markdown محلی
در کنار حافظه میان‌نشستی Honcho در دسترس قرار می‌گیرند.

## فرمان‌های CLI

```bash
openclaw honcho setup                        # پیکربندی کلید API و مهاجرت فایل‌ها
openclaw honcho status                       # بررسی وضعیت اتصال
openclaw honcho ask <question>               # پرس‌وجو از Honcho درباره کاربر
openclaw honcho search <query> [-k N] [-d D] # جست‌وجوی معنایی در حافظه
```
