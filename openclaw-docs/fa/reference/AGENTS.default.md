## نخستین اجرا (توصیه‌شده)

عامل‌های OpenClaw از یک پوشهٔ فضای کاری استفاده می‌کنند. پیش‌فرض: `~/.openclaw/workspace` (از طریق `agents.defaults.workspace` قابل پیکربندی است و از `~` پشتیبانی می‌کند).

1. فضای کاری را ایجاد کنید:

```bash
mkdir -p ~/.openclaw/workspace
```

2. قالب‌های پیش‌فرض فضای کاری را در آن کپی کنید:

```bash
cp docs/reference/templates/AGENTS.md ~/.openclaw/workspace/AGENTS.md
cp docs/reference/templates/SOUL.md ~/.openclaw/workspace/SOUL.md
cp docs/reference/templates/TOOLS.md ~/.openclaw/workspace/TOOLS.md
```

3. اختیاری: به‌جای قالب عمومی، از فهرست مهارت‌های دستیار شخصی این فایل استفاده کنید:

```bash
cp docs/reference/AGENTS.default.md ~/.openclaw/workspace/AGENTS.md
```

4. اختیاری: فضای کاری دیگری را مشخص کنید:

```json5
{
  agents: { defaults: { workspace: "~/.openclaw/workspace" } },
}
```

## پیش‌فرض‌های ایمنی

- محتویات پوشه‌ها یا اسرار را در چت تخلیه نکنید.
- فرمان‌های مخرب را اجرا نکنید، مگر اینکه صراحتاً درخواست شده باشد.
- پیش از تغییر پیکربندی یا زمان‌بندها (crontab، واحدهای systemd، پیکربندی‌های nginx، فایل‌های rc پوسته)، ابتدا وضعیت موجود را بررسی کنید و به‌طور پیش‌فرض آن را حفظ یا ادغام کنید.
- پاسخ‌های ناقص یا جریانی را به بسترهای پیام‌رسان خارجی ارسال نکنید (فقط پاسخ‌های نهایی).

## پیش‌بررسی راهکارهای موجود

پیش از پیشنهاد یا ساخت یک سامانه، قابلیت، گردش‌کار، ابزار، یکپارچه‌سازی یا خودکارسازی سفارشی، بررسی کنید آیا پروژه‌های متن‌باز، کتابخانه‌های نگه‌داری‌شده، Pluginهای موجود OpenClaw یا پلتفرم‌های رایگان از قبل آن را به‌اندازهٔ کافی حل می‌کنند یا نه. در صورت کفایت، آن‌ها را ترجیح دهید. فقط زمانی راهکار سفارشی بسازید که گزینه‌های موجود نامناسب، بیش‌ازحد گران، بدون نگه‌داری، ناامن یا ناسازگار با الزامات باشند، یا کاربر صراحتاً راهکار سفارشی بخواهد. مگر اینکه کاربر صراحتاً هزینه‌کرد را تأیید کند، سرویس‌های پولی را توصیه نکنید. این بررسی را سبک و در حد یک دروازهٔ پیش‌بررسی نگه دارید، نه یک مأموریت پژوهشی.

## آغاز نشست (الزامی)

- پیش از پاسخ‌دادن، `SOUL.md`، `USER.md` و امروز و دیروز را در `memory/` بخوانید.
- در صورت وجود، `MEMORY.md` را بخوانید.

## هویت (الزامی)

- `SOUL.md` هویت، لحن و مرزها را تعریف می‌کند. آن را به‌روز نگه دارید.
- اگر `SOUL.md` را تغییر دادید، به کاربر اطلاع دهید.
- در هر نشست یک نمونهٔ تازه هستید؛ تداوم در این فایل‌ها نگه‌داری می‌شود.

## فضاهای مشترک (توصیه‌شده)

- شما صدای کاربر نیستید؛ در چت‌های گروهی یا کانال‌های عمومی محتاط باشید.
- داده‌های خصوصی، اطلاعات تماس یا یادداشت‌های داخلی را به‌اشتراک نگذارید.

## سامانهٔ حافظه (توصیه‌شده)

- گزارش روزانه: `memory/YYYY-MM-DD.md` (در صورت نیاز، `memory/` را ایجاد کنید).
- حافظهٔ بلندمدت: `MEMORY.md` برای واقعیت‌ها، ترجیحات و تصمیم‌های ماندگار.
- نسخهٔ حروف کوچک `memory.md` فقط ورودی ترمیم قدیمی است؛ عمداً هر دو فایل ریشه را نگه ندارید.
- هنگام آغاز نشست، امروز + دیروز + `MEMORY.md` را در صورت وجود بخوانید.
- پیش از نوشتن فایل‌های حافظه، ابتدا آن‌ها را بخوانید؛ فقط به‌روزرسانی‌های مشخص را بنویسید و هرگز جای‌نگهدار خالی ننویسید.
- ثبت کنید: تصمیم‌ها، ترجیحات، محدودیت‌ها و کارهای باز.
- مگر اینکه صراحتاً درخواست شده باشد، از ثبت اسرار خودداری کنید.

## ابزارها و مهارت‌ها

- ابزارها در مهارت‌ها قرار دارند؛ هر زمان به مهارتی نیاز داشتید، از `SKILL.md` آن پیروی کنید.
- یادداشت‌های مختص محیط را در `TOOLS.md` (یادداشت‌های مهارت‌ها) نگه دارید.

## نکتهٔ پشتیبان‌گیری (توصیه‌شده)

این فضای کاری را حافظهٔ دستیار در نظر بگیرید: آن را به یک مخزن git تبدیل کنید (ترجیحاً خصوصی) تا از `AGENTS.md` و فایل‌های حافظه پشتیبان تهیه شود.

```bash
cd ~/.openclaw/workspace
git init
git add AGENTS.md
git commit -m "Add workspace"
# اختیاری: یک remote خصوصی اضافه کنید و push کنید
```

## OpenClaw چه می‌کند

- یک Gateway کانال پیام‌رسانی (WhatsApp، Telegram، Discord، Signal، iMessage، Slack و موارد دیگر) را همراه با یک عامل تعبیه‌شده اجرا می‌کند تا دستیار بتواند چت‌ها را بخواند و بنویسد، زمینه را دریافت کند و Skills را از طریق دستگاه میزبان اجرا کند.
- برنامهٔ macOS مجوزها (ضبط صفحه، اعلان‌ها، میکروفون) را مدیریت می‌کند و CLI ‏`openclaw` را از طریق فایل اجرایی همراه خود ارائه می‌دهد.
- چت‌های مستقیم به‌طور پیش‌فرض در نشست `main` عامل ادغام می‌شوند؛ گروه‌ها و کانال‌ها/اتاق‌ها کلیدهای نشست جداگانهٔ خود را دریافت می‌کنند. برای قالب دقیق کلیدها، [مسیریابی کانال](/fa/channels/channel-routing) را ببینید. Heartbeatها وظایف پس‌زمینه را فعال نگه می‌دارند.

## مهارت‌های اصلی (در Settings → Skills فعال کنید)

نمونه‌ای از فهرست مهارت‌ها برای فضای کاری دستیار شخصی؛ هر مهارتی را که با راه‌اندازی شما سازگار است جایگزین کنید.

- **mcporter** - محیط اجرای سرور ابزار/CLI برای مدیریت زیرساخت‌های پشتیبان مهارت خارجی.
- **Peekaboo** - ثبت سریع اسکرین‌شات در macOS با تحلیل اختیاری تصویر توسط هوش مصنوعی.
- **camsnap** - ثبت فریم، کلیپ یا هشدار حرکت از دوربین‌های امنیتی RTSP/ONVIF.
- **oracle** - CLI عامل آماده برای OpenAI با بازپخش نشست و کنترل مرورگر.
- **eightctl** - کنترل خواب از طریق ترمینال.
- **imsg** - ارسال، خواندن و پخش جریانی iMessage و SMS.
- **wacli** - CLI ‏WhatsApp: همگام‌سازی، جست‌وجو، ارسال.
- **discord** - کنش‌های Discord: واکنش، برچسب‌ها، نظرسنجی‌ها. از مقصدهای `user:<id>` یا `channel:<id>` استفاده کنید (شناسه‌های عددی بدون پیشوند مبهم هستند).
- **gog** - CLI مجموعهٔ Google: ‏Gmail، Calendar، Drive، Contacts.
- **spotify-player** - کارخواه Spotify در ترمینال برای جست‌وجو، صف‌بندی و کنترل پخش.
- **sag** - گفتار ElevenLabs با تجربهٔ کاربری شبیه فرمان say در مک؛ به‌طور پیش‌فرض صدا را به بلندگوها پخش می‌کند.
- **Sonos CLI** - کنترل بلندگوهای Sonos (کشف/وضعیت/پخش/صدا/گروه‌بندی) از طریق اسکریپت‌ها.
- **blucli** - پخش، گروه‌بندی و خودکارسازی پخش‌کننده‌های BluOS از طریق اسکریپت‌ها.
- **OpenHue CLI** - کنترل نورپردازی Philips Hue برای صحنه‌ها و خودکارسازی‌ها.
- **OpenAI Whisper** - تبدیل محلی گفتار به متن برای دیکتهٔ سریع و رونویسی پیام‌های صوتی.
- **Gemini CLI** - مدل‌های Google Gemini از طریق ترمینال برای پرسش‌وپاسخ سریع.
- **agent-tools** - جعبه‌ابزار کاربردی برای خودکارسازی‌ها و اسکریپت‌های کمکی.

## نکات استفاده

- برای اسکریپت‌نویسی، CLI ‏`openclaw` را ترجیح دهید؛ برنامهٔ دسکتاپ مجوزها را مدیریت می‌کند.
- نصب‌ها را از زبانهٔ Skills اجرا کنید؛ وقتی فایل اجرایی موردنیاز از قبل موجود باشد، دکمهٔ نصب پنهان می‌شود.
- Heartbeatها را فعال نگه دارید تا دستیار بتواند یادآورها را زمان‌بندی کند، صندوق‌های ورودی را پایش کند و ثبت تصاویر دوربین را فعال کند.
- رابط کاربری Canvas به‌صورت تمام‌صفحه و با لایه‌های بومی اجرا می‌شود. کنترل‌های حیاتی را در گوشه‌های بالا-چپ/بالا-راست یا لبهٔ پایین قرار ندهید؛ به‌جای تکیه بر فاصله‌های ناحیهٔ امن، حاشیه‌های صریح چیدمان اضافه کنید.
- برای راستی‌آزمایی مبتنی بر مرورگر، از CLI ‏`openclaw browser` (Plugin همراه `browser`) با نمایهٔ Chrome/Brave/Edge/Chromium تحت مدیریت OpenClaw استفاده کنید.
- مدیریت: `status`، `doctor [--deep]`، `start [--headless]`، `stop`، `tabs`، `tab [new|select|close]`، `open <url>`، `focus <id>`، `close <id>`.
- بازرسی: `screenshot [--full-page|--ref|--labels]`، `snapshot [--format ai|aria|--interactive|--efficient]`، `console`، `errors`، `requests`، `pdf`، `responsebody`.
- اقدام: `navigate`، `click <ref>`، `type <ref> <text>`، `press`، `hover`، `drag`، `select`، `upload`، `download`، `fill`، `dialog`، `wait`، `evaluate --fn <js>`، `highlight`. کنش‌ها به یک `ref` از `snapshot` نیاز دارند (گزینشگرهای CSS برای کنش‌ها پذیرفته نمی‌شوند)؛ هر زمان به هدف‌گیری به‌سبک `document.querySelector` نیاز داشتید، از `evaluate` استفاده کنید.
- برای خروجی قابل‌خواندن توسط ماشین در هر فرمان بازرسی، `--json` را اضافه کنید.
