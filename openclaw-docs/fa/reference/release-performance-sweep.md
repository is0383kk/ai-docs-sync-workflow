این صفحه شواهد مربوط به پاک‌سازی عملکرد، اندازه بسته، وابستگی‌ها و shrinkwrap در OpenClaw در مه ۲۰۲۶ را ثبت می‌کند. این صفحه همراه فنی پست عمومی وبلاگ است.

دو ممیزی در اینجا ترکیب شده‌اند:

- **بررسی جامع عملکرد انتشار:** GitHub Releases از `v2026.5.28` تا نسخه پایدار `v2026.4.23`، با استفاده از گردش‌کار `OpenClaw Performance`، مسیر `profile=smoke` و ارائه‌دهنده آزمایشی. بیشتر ردیف‌های برچسب یک نمونه دارند؛ ردیف‌های `v2026.5.27` و `v2026.5.28` از جدیدترین مصنوعات شاخه انتشار با ۳ تکرار استفاده می‌کنند.
- **زمینه پیشین آوریل:** خط‌مبناهای منتشرشده ارائه‌دهنده آزمایشی `clawgrit-reports` از `v2026.4.1` تا `v2026.5.2`، که فقط برای جلوگیری از درنظرگرفتن انتشارهای خراب اواخر آوریل به‌عنوان خط‌مبنای عمومی عملکرد استفاده شده‌اند.
- **بررسی جامع ردپای نصب:** نصب‌های تازه `npm install --ignore-scripts` در بسته‌های موقت، با `du -sk node_modules` برای اندازه و پیمایش `node_modules` برای شمارش نمونه‌های بسته.
- **بررسی جامع اندازه بسته npm:** `npm pack openclaw@<version> --dry-run --json` برای انتشارهای منتشرشده، با ثبت اندازه tarball فشرده، اندازه بازشده و تعداد فایل‌ها.

<Warning>
بررسی جامع اصلی عملکرد برای هر برچسب از یک نمونه دود استفاده می‌کند، به‌جز ردیف‌های `v2026.5.27` و `v2026.5.28` که از جدیدترین مصنوعات شاخه انتشار با ۳ تکرار استفاده می‌کنند. زمینه پیشین آوریل از میانه‌های منتشرشده با ۳ تکرار از `clawgrit-reports` استفاده می‌کند. این اعداد را شواهد روند و نشانه‌ای برای یافتن پسرفت بدانید، نه آمار گیت انتشار.
</Warning>

به [shrinkwrap در npm](/fa/gateway/security/shrinkwrap) مراجعه کنید.

## تفسیر زنجیره تأمین

تعداد وابستگی‌ها یک معیار امنیت عملیاتی است، نه فقط معیاری برای اندازه نصب.
هر بسته مجموعه نگه‌دارندگان، tarballها، به‌روزرسانی‌های گذرا،
باینری‌های بومی اختیاری و رفتارهای زمان نصب را که اپراتورها
باید به آن‌ها اعتماد کنند، گسترش می‌دهد.

جهت پاک‌سازی چنین است:

- قابلیت‌های سنگین و اختیاری را بیرون از نصب پیش‌فرض هسته نگه دارید
- بسته‌های Plugin را مالک نمودار وابستگی زمان اجرای خود کنید
- از ترمیم مدیر بسته در زمان اجرا هنگام راه‌اندازی Gateway اجتناب کنید
- نصب‌های قطعی را بدون ایجاد تحقق بسته‌های بومی همه پلتفرم‌ها
  حفظ کنید
- اسکریپت‌های نصب را در مسیرهای پذیرش و اندازه‌گیری بسته غیرفعال نگه دارید
- درخت‌های وابستگی تودرتو و انفجار وابستگی‌های بومی اختیاری را پیش از
  انتشار شناسایی کنید
