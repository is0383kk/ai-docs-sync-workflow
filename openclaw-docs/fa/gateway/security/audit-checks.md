`openclaw security audit` یافته‌های ساختاریافته‌ای را با کلید `checkId` منتشر می‌کند. این
صفحه، کاتالوگ مرجع آن شناسه‌ها است. برای مدل تهدید سطح‌بالا
و راهنمای مقاوم‌سازی، به [امنیت](/fa/gateway/security) مراجعه کنید.

برخی بررسی‌ها فقط با `openclaw security audit --deep` اجرا می‌شوند: اسکن‌های کد Plugin/skill
(`plugins.code_safety*`، `skills.code_safety*`) و بررسی‌های کاوش زنده Gateway
(`gateway.probe_*`). همه موارد دیگر این جدول با یک
`openclaw security audit` ساده اجرا می‌شوند.

شدتی مانند `warn/critical` به این معنا است که همان `checkId` بسته به
پیکربندی می‌تواند در هر یک از این دو سطح منتشر شود (برای مثال، بسته به اینکه Gateway از راه دور
در دسترس باشد یا نه). مقادیر با سیگنال بالا که به‌احتمال زیاد در استقرارهای واقعی مشاهده خواهید کرد (این فهرست
